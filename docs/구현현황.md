## 2026-08-08 build 변경

- `KAKAO_ALIMTALK_SENDER_KEY` 의존을 제거했다.
- `KAKAO_ALIMTALK_FROM`과 `KAKAO_ALIMTALK_TEMPLATE_CHEER_RECEIVED`를 추가했다.
- `KAKAO_ALIMTALK_API_URL/API_KEY/API_SECRET/PFID` 기존 이름은 유지했다.
- 템플릿 치환 키 `#{응원자}`, `#{목표}`와 결제 성공 응답은 변경하지 않았다.
- 이번 요청에 따라 배포하지 않았다. 실 Solapi 왕복과 카카오 수신은 미검증이다.
