## 남은 검증과 경계

- 인증된 실제 계정의 30/27 화면은 QA 단계에서 브라우저로 다시 대조한다.
- 운영 쓰기 경로는 실제 환전 거래를 만들지 않는 정책 때문에 이번 build에서 재실행하지 않았다.
- 실제 운영 Toss 결제창 끝단은 거래 생성 금지 정책으로 미검증이다. 배포 후 기존 결제 E2E로 재검증한다.
- 전역 디자인 lint에는 이번 변경 밖 기존 인라인 style과 hex 경고가 있다. cashout 디렉터리는 0건이다.
- 전체 테스트는 PASS지만 기존 `NotificationBadge` 테스트의 React `act(...)` 경고가 남는다. 실패는 아니며 별도 테스트 위생 보정 대상이다.
