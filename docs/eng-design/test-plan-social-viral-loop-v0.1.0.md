## 1. 전략과 레이어

머신 과부하 상태라 이 단계는 계획만 쓴다. 실행은 qa 단계(dev 배포본 대상).

## 3. D-003 전용 검증(최우선 불변식)

TC-D003은 3층에서 교차검증한다.
1. DB 계약: 소셜 view·RPC 반환 컬럼 목록에 금액·순위 필드가 0인지 information_schema로 단정.
2. API: 각 소셜 응답 JSON 키 집합에 금지 필드 0.
3. DOM: 렌더 결과에 금액·순위 텍스트·토글 0(프로토 `rankSw` 제거 확인).

하나라도 실패면 전체 FAIL. 이 테스트는 리그레션에 영구 등록(회귀 방지).

## 4. 회귀 보호 (이웃 안 깨짐)

- 기존 결제·환전·워드맵·알림 플로우(FDD §7.1-7.2의 운영 53스텝)는 goal 컬럼 추가·view 변경 후에도 green이어야 한다.
- `goal` 컬럼 추가가 `goal_public`·`cheer_public`·멀티골 생성·cashout 잠금에 영향 없음을 리그레션으로 고정.
- 픽스처 등록: 커버 미설정 기존 목표가 프리셋으로 정상 렌더되는 케이스를 회귀 픽스처로.
