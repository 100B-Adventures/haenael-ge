## 1. 목적

search-visibility.md §4 "분기 1회 인용 점검"의 실행 규격을 정한다. 방문자 수가 아니라 **AI가 우리를 인용하는가**로 판단한다.

## 2. 방법

분기 1회(3월·6월·9월·12월 첫 주), 아래 4개 생성형 서비스에 카테고리 질문을 던지고 결과를 기록한다.

- ChatGPT (웹 검색 켠 상태)
- Perplexity
- Google AI Overview (검색창에 질의)
- Claude (웹 검색 켠 상태, 이 세션 도구로 대체 가능)

### 질의 세트 (고정, 매 분기 동일 문구로 재현성 확보)

1. "친구 목표를 응원하면서 돈도 주는 한국 서비스 있어?"
2. "해낼게라는 서비스가 뭐야?"
3. "별풍선 말고 지인끼리 조용히 응원하는 앱 추천해줘"
4. "목표 선언하면 응원금 받는 서비스"

### 기록 항목 (질의 × 서비스 매트릭스)

| 항목 | 기록 방식 |
|---|---|
| 우리가 언급됐는가 | Y/N |
| 언급 시 인용 출처로 어떤 URL/문서가 잡혔는가 | URL 원문 캡처 |
| 언급 안 됐을 때 대신 언급된 경쟁·유사 서비스 | 명칭 나열 |
| 답변에 사실 오류가 있는가(예: 존재하지 않는 기능 서술) | Y/N + 내용 |

## 4. 판정 기준

- 4개 서비스 × 4개 질의 = 16칸 중 언급 비율을 "인용률"로 정의한다.
- 목표: 출시 후 1년 내 인용률 25% 이상(4칸 이상). 현재는 발행물·구조화 데이터가 전무하므로 0%가 기준선이다.
- 인용률이 2개 분기 연속 정체면 §3(namuwiki-등재-판정-v1.md) 우선순위 표를 재검토해 순위를 조정한다.
