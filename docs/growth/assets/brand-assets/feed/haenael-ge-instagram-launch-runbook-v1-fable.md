# 해낼게 인스타그램 런치 실행서 v1

> 목적: 회장이 인스타그램·스레드 앱을 보면서 위에서 아래로 그대로 실행하는 단일 복붙 문서.
>
> 실행 원칙: 새 전략·새 카피를 만들지 않는다. 기존 검증 문구를 발행 순서로만 배열한다. 앱 메뉴명이 이 문서와 다르면 추측해 진행하지 말고 `확인 필요`로 멈춘다.
>
> 퍼널: 인지 → 호기심 → 선언 링크 방문.
> 측정: 프로필 방문→팔로우 전환, 게시물 댓글률, 프로필 링크 클릭, DM의 S3 행동 신호(링크 허락 또는 선언 생성).

- [ ] 표시 이름이 `해낼게 ⏐ 목표 선언 응원`과 글자까지 같다.

## 1. 공통 게시 방법

아래 9개 게시물을 반드시 이 순서로 올린다.

```text
09 → 07 → 04 → 05 → 06 → 03 → 08 → 02 → 01
```

게시물마다 다음 순서를 반복한다.

1. 인스타그램 앱에서 새 게시물 `+`를 누른다.
2. 지정된 이미지 또는 캐러셀 자산을 선택한다.
3. 원본 비율 4:5가 유지되고 상하좌우 글자가 잘리지 않는지 미리보기에서 확인한다.
4. 아래 `캡션 전체`를 그대로 붙여넣는다.
5. 게시한다.
6. 브랜드 계정으로 아래 `첫 댓글 전체`를 그대로 남긴다.
7. 첫 댓글을 길게 누르거나 댓글 옵션을 열어 `고정`한다.
8. 고정 메뉴명이 없거나 본인 댓글 고정이 제공되지 않으면 **확인 필요**로 기록한다. 다른 댓글을 대신 만들지 않는다.
9. 게시 직후 해당 게시물의 `게시 직후 30초 확인`을 끝내고 다음 게시물로 넘어간다.

## 15. 레드팀·셀프심문

**레드팀 — 까다로운 런치 실행자:** “ZIP에는 5장이 있어도 휴대폰 사진 선택기에서 한 장이 누락되거나 선택 순서가 뒤집히면, 5장 캐러셀이 잘못된 상태로 그대로 발행되는 것 아닌가?”
수정 반영: ZIP 저장·압축 해제를 전체 실행의 첫 단계로 올리고, 14개 구성과 feed-02의 1~5장 정확 경로를 적었다. 한 장이라도 사진 선택기에 안 보이면 `feed-02`만 멈추고 선택기 스크린샷을 요청하며, 단일 이미지 대체·순서 변경·카피 수정은 금지했다.

**셀프심문 — 이 단계가 틀렸다면 가장 그럴듯한 이유는?**
로컬 파일과 ZIP은 정상이지만 휴대폰 전송·압축 해제·사진 앱 권한 단계에서 일부 PNG가 사진 선택기에 나타나지 않을 수 있다. 그래서 로컬 존재를 모바일 노출 완료로 과장하지 않고, 5장 중 하나라도 안 보이면 해당 게시물만 멈춰 앨범명과 썸네일이 보이는 스크린샷을 받도록 수정했다.

**가장 무거운 잔존 가정:** 휴대폰 사진 앱이 ZIP에서 저장한 5장을 모두 인스타그램 사진 선택기에 노출하고, 실행자가 선택한 1~5 순서를 게시 전 미리보기까지 유지한다는 가정이다. 로컬 자산·ZIP·디자인은 검증됐지만 실제 계정의 모바일 게시 경로는 아직 미검증이다.
