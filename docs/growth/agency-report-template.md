### 입력 규칙

- 플랫폼 값은 `Instagram`, `Threads`, `YouTube` 중 하나다.
- 발행 URL은 공개 상태에서 열리는 게시물 단위 URL이어야 한다. 프로필 홈 URL은 인정하지 않는다.
- 아웃바운드 클릭을 플랫폼에서 제공하지 않으면 `미파악`으로 쓴다. 클릭이 없음을 확인한 경우만 `0`이다.
- 노출·도달·조회는 원인 진단용이다. 승강 판정 수치로 쓰지 않는다.
- `@haenaelge`가 아닌 계정에서 발행했다면 계정 식별자를 URL 옆에 적고 사유를 D 절에 쓴다.
