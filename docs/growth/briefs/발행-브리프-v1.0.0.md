# 해낼게 외주 발행 브리프 v1.0.0

이번 분기 목표는 도움 요청이 아니라 목표 선언이 퍼지고, 친구의 조용한 응원이 측정 가능한 링크를 따라 들어오는 구조를 만드는 것이다.

## 1. 퍼널과 독자

- 확산 단계: 관심 → 사용 → 반응 → 바이럴 → 추천.
- 선언자: 편입·재수·자격증·이직·다이어트처럼 공개 약속이 필요한 사람.
- 응원자: 기프티콘의 답례 부담 없이 친구를 밀어주고 싶은 사람.
- 심리 장치: 공개 커밋먼트, 조용한 상호성, 목격자 효과, 선언 카드 공유.

## 2. 이번 분기 주제 축

1. **말하면 시작된다:** 목표 한 줄, D-day, 기간으로 선언한다.
2. **휘발되는 화이팅:** 하트와 말이 사라지는 관습을 사람 비난 없이 다룬다.
3. **조용히 두고 가는 마음:** 이름·금액 노출 없이 응원하는 매너.
4. **해내면 네 것:** 달성 뒤 클로버가 전달되는 구조. 실제 운영 범위만 말한다.
5. **만드는 중:** 제품 결정·실패·수수료·안전선을 공개한다.

## 3. 채널별 형식과 분량

| 채널 | 형식 | 분량 | CTA |
|---|---|---|---|
| Instagram | 선언 카드, 6장 캐러셀, 15∼25초 릴스 | 캡션 200∼500자 | `한 줄 선언하기` |
| Threads | 도발 1문장 + 제작기 3∼6개 연속 글 | 편당 80∼220자 | 선언 페이지 또는 제작기 답글 |
| YouTube | 선언자 로그·제작기 | Shorts 25∼45초, 롱폼 4∼8분 | 설명란 선언 링크 |

Instagram은 주인공 면이라 돈 언어를 빼고, Threads·YouTube는 응원자 면에서 슬로건을 쓸 수 있다.

## 4. 후킹 수위

- raw provocative: `응원은 돈으로 하는 겁니다.`
- safer publish: `말하면 시작된다. 해낼게.`
- risk label: `surface-dependent`. raw는 Threads·YouTube·응원자 콘텐츠에 허용되지만 선언 카드·주인공 페이지에는 금지다.

## 5. 반드시 지킬 것

- 링크 규격은 [tag-spec.md](../tag-spec.md)를 참조한다. 캠페인 값을 이 문서에 복제하지 않는다.
- Instagram 현재 운영 계정은 `@haenaelge`다. Threads·YouTube는 개설 전 발행하지 않는다.
- 선언 페이지·공유 카드에는 돈·후원·도네·환전 단어를 넣지 않는다.
- 인원수는 실제 값만 쓴다. 0명이면 첫 응원 프레임을 쓴다.
- 선언 예시는 예시라고 표시한다. 실사용자처럼 꾸미지 않는다.
- 발행 URL·실제 태그·아웃바운드 클릭·발행 시각을 회신한다.

## 8. 레드팀과 셀프심문 반영

회의적인 사용자는 "친구 돈을 걷는 구걸 서비스"라고 공격한다. 요청형 언어 금지, 선언자 면 돈 언어 0, 응원자 신원·금액 비노출을 동시에 고정했다.

이 설계가 틀렸다면 가장 그럴듯한 이유는 돈 언어를 숨긴 결과 결제 구조가 뒤늦게 드러나 신뢰를 잃는 경우다. 그래서 주인공 공유면에서는 숨기되, 응원자 결제 터치포인트에서는 금액·조건·환전 구조를 정확히 공개한다.
