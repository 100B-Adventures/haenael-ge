## 1. 계정 개설 — 오늘 30분

### 1-1. 시작 전 준비

- [ ] 인스타그램 가입에 사용할 브랜드 이메일 또는 전화번호를 준비했다.
- [ ] 비밀번호는 이 문서나 공유 메모에 적지 않는다.
- [ ] 휴대폰에 아래 프로필 사진이 저장돼 있다.

```text
docs/growth/assets/brand-assets/profile-icon.png
```

실물 확인: 존재함 · 512×512.

### 1-2. 가입 화면에서 핸들 입력

인스타그램 앱의 신규 계정 만들기에서 아래 순서대로 **하나씩 실제 가용성을 확인**한다. 앞 핸들이 사용 가능하면 뒤 핸들은 시도하지 않는다.

1. `haenaelge`
2. `haenaelge_official`
3. `haenaelge_app`
4. `haenael.ge`

- [ ] 사용 가능 표시를 직접 확인한 뒤 가입을 끝냈다.
- [ ] 확정 핸들을 이 문서 맨 끝 결정 박스에 기록했다.
- [ ] Instagram·Threads·향후 YouTube에 같은 핸들을 쓴다는 원칙을 유지했다.

핸들 실제 가용성은 가입 화면을 보기 전까지 **미검증**이다.

### 1-3. 프로필 편집 — 아래 값 그대로 복붙

인스타그램 앱 → 우하단 프로필 → `프로필 편집`.

**프로필 사진**

```text
docs/growth/assets/brand-assets/profile-icon.png
```

**이름 필드**

```text
해낼게 ⏐ 목표 선언 응원
```

**바이오 — `docs/growth/assets/brand-assets/feed/bio-ready.md` 정본 그대로**

```text
말하면 시작된다. 해낼게 🍀
친구의 목표 선언에, 조용히 마음을 두고 가는 곳
선언은 프로필 링크에서 👇
```

**링크**

```text
https://haenael-ge.vercel.app/
```

이 URL은 `web/src/proxy.ts`의 canonical host와 최근 운영 관찰이 일치한다. `https://haenaelge.vercel.app/`는 레거시 별칭이므로 바이오에는 넣지 않는다.

### 1-4. 프로페셔널 계정 전환

인스타그램 앱 → 설정 및 활동 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환.

- 계정 유형: `비즈니스`
- 카테고리: `제품/서비스`
- 공개 상태: `공개`

**Creator가 아니라 Business인 이유**

- 해낼게는 개인 창작자·인플루언서가 아니라 고객을 모집하고 서비스를 운영하는 브랜드다.
- Meta 공식 도움말은 Business를 고객 도달·성장을 원하는 사업체용으로 구분한다.
- 인사이트, 카테고리 라벨, Primary/General/Requests로 나뉜 보조 받은편지함이 DM 운영에 필요하다.

메뉴명이 실제 앱과 다르면 비슷해 보이는 항목을 추측 선택하지 말고 화면을 캡처한다.

### 1-5. Threads 연결

**오늘 연결한다.**

1. Threads 앱 또는 `https://www.threads.com`을 연다.
2. 방금 만든 해낼게 인스타그램 계정으로 로그인한다.
3. 프로필 사진과 핸들을 가져온다.
4. Threads의 바이오와 링크는 나중에 별도로 수정할 수 있다. Meta 공식 도움말상 Threads의 바이오·링크·사진 수정은 Instagram 프로필을 바꾸지 않는다.

- [ ] Instagram 프로필의 바이오가 바뀌지 않았는지 다시 확인했다.
- [ ] Threads 핸들이 Instagram 확정 핸들과 같은지 확인했다.

### 1-6. 30분 종료 확인

- [ ] 프로필 사진이 원형 크롭에서도 클로버형 대칭 마크로 보인다.
- [ ] 이름 필드가 `해낼게 ⏐ 목표 선언 응원`과 글자까지 같다.
- [ ] 바이오 3줄이 정본과 글자까지 같다.
- [ ] 링크가 `https://haenael-ge.vercel.app/`다.
- [ ] 계정 유형이 비즈니스, 카테고리가 제품/서비스다.
- [ ] Threads가 해낼게 계정에 연결됐다.
- [ ] 결제·환전 가능 문구를 프로필에 추가하지 않았다.

## 2. 하이라이트 6종 세팅

`W1_START_DATE=2026-07-27` 확인 전에는 파일을 휴대폰에 저장하는 데까지만 한다. 하이라이트 커버도 스토리 발행이므로 W1 미확인 상태에서 올리지 않는다.

### 2-1. 실물 확인 결과

| 목표 순서 | 실제 파일 경로 | 실측 규격 | 하이라이트 이름 |
|---:|---|---:|---|
| 1 | `docs/growth/assets/brand-assets/highlight-01-해낼게란.png` | 1080×1920 | `🍀 해낼게란` |
| 2 | `docs/growth/assets/brand-assets/highlight-02-선언하는법.png` | 1080×1920 | `선언하는 법` |
| 3 | `docs/growth/assets/brand-assets/highlight-03-클로버.png` | 1080×1920 | `클로버` |
| 4 | `docs/growth/assets/brand-assets/highlight-04-응원매너.png` | 1080×1920 | `응원 매너` |
| 5 | `docs/growth/assets/brand-assets/highlight-05-만드는중.png` | 1080×1920 | `만드는 중` |
| 6 | `docs/growth/assets/brand-assets/highlight-06-물어보세요.png` | 1080×1920 | `물어보세요` |

### 2-2. 폰에서 실행

목표 최종 배열은 왼쪽부터 `🍀 해낼게란 → 선언하는 법 → 클로버 → 응원 매너 → 만드는 중 → 물어보세요`다.

1. 위 PNG 6장을 휴대폰 사진 앱에 저장한다.
2. **업로드 순서: 06 → 05 → 04 → 03 → 02 → 01.**
3. 각 PNG를 스토리에 한 장씩 올린 직후, 그 스토리만 새 하이라이트로 묶고 표의 이름을 입력한다.
4. 마지막에 프로필로 돌아와 왼쪽부터 01→06 순서인지 확인한다.
5. 배열이 다르면 재업로드하지 말고 화면을 캡처한다. Meta 공식 도움말은 하이라이트 생성·편집은 설명하지만 정렬 규칙까지 보장하지 않으므로, 실제 앱 결과가 증거다.

각 하이라이트의 첫 스토리는 지금 올린 커버다. 이후 넣을 내용은 정본 기준으로 다음과 같다.

| 이름 | 이후 추가할 내용 |
|---|---|
| 🍀 해낼게란 | 해낼게가 무엇인지 설명하는 카드 |
| 선언하는 법 | 선언 생성·프로필 링크 사용법 |
| 클로버 | 클로버 어휘 정의와 현재 기능 상태 |
| 응원 매너 | 익명·비동기·답례 부담 없음 |
| 만드는 중 | 제작기·운영 과정 |
| 물어보세요 | FAQ·수수료·현재 미검증 상태 |

## 4. DM 아웃바운드 실행

### 4-1. 오늘 목표

- 총 프리테스트 표본: 15명.
- 오늘 실제 발송: W1 개시 확인 후 **최대 5명**.
- 이후: 하루 5명씩 3일에 나눠 총 15명.
- 첫 DM에는 링크를 넣지 않는다.
- 발송 주체는 창업자 개인 계정이 아니라 **해낼게 브랜드 계정**이다.
- 제3자 자동화·대량 발송 도구를 쓰지 않는다. 발송과 답장은 사람이 직접 한다.

근거: 신규 계정은 행동 신뢰가 없고 정본 플레이북의 W0 상한이 0~5통이다. 프리테스트 정본도 30일 미만 계정은 하루 5~8통으로 분산하라고 정한다. 오늘은 둘 중 더 보수적인 **5통**을 적용한다.

### 4-2. 대상 선별 — 전부 충족

- [ ] 마지막 게시물이 7일 이내다.
- [ ] 바이오 또는 최근 게시물 3개 안에 시험명·D-day·합격·자격증 같은 목표가 문자로 보인다.
- [ ] 팔로워 100~3,000명이다.
- [ ] 공부계·부계·기록용 bio, 얼굴 없는 플래너·책상 피드, 본명 아닌 핸들, 공스타 위주 팔로잉 중 2개 이상이 보인다.
- [ ] 편입 3명 + 자격증 또는 공시 2명으로 오늘 5명을 구성한다.
- [ ] 업체·학원·스터디 모집 계정이 아니다.
- [ ] 예전에 DM을 보냈거나 수신 거부한 계정이 아니다.
- [ ] 첫 줄에 넣을 실제 개인화 소재가 있다.

### 4-3. 미성년 제외 처리

아래 중 하나라도 보이면 **발송하지 않는다**.

- 중학생·고등학생·고3이라고 직접 적혀 있다.
- 학교·교복·학년 등으로 미성년 가능성이 높다.
- 나이가 불명확한데 재수생·성인이라는 근거도 없다.

재수생도 `만 19세 이상` 또는 성인임이 명확한 경우만 포함한다. 애매하면 제외하고 DM 원장 note에 `연령 불명확 — 제외`라고 적는다. 대상 수를 채우기 위해 추정하지 않는다.

### 4-4. 첫 접촉 DM — 완성본

아래 문안은 **최근 게시물에 목표와 D-day를 함께 적은 계정**에만 보낸다. 그 조건이 없으면 문안을 억지로 바꾸지 말고 대상을 제외한다.

```text
최근 게시물에 목표와 D-day를 함께 기록하신 걸 보고 왔어요. 그 기록을 계속 이어가고 계신 게 눈에 들어왔어요.
저희는 '해낼게'라는 곳을 만들고 있어요. 목표를 선언하면 전용 페이지가 생기고, 아는 사람들이 말뿐인 '화이팅' 대신 조용히 마음을 두고 갈 수 있는 곳이에요.
정직하게 말씀드리면 아직 공사 중이에요. 지금은 선언까지만 열려 있고, 마음이 실제로 전해지는 부분은 마무리하는 중이에요. 그래서 지금 오시는 분들은 말 그대로 이 목표의 첫 선언자가 되고, 의견은 만드는 사람들이 직접 듣고 고쳐요. 응원이 열리는 날엔 제일 먼저 알려드리고요.
첫 선언 자리에 어울리는 기록이라고 생각해서 연락드렸어요. 어떤 곳인지 먼저 보실 수 있게, 페이지 하나만 보내드려도 될까요?
```

발송 전 더 구체화할 수 있으면 첫 문장만 상대의 실제 기록으로 바꾼다. 예:

```text
D-97 플래너에 새벽 5시 반 기상 도장까지 보고 왔어요. 그걸 8개월째 해내고 계신 거, 그냥 지나치기가 어려웠어요.
```

**발송 금지 조건**

- 상대 게시물에 목표와 D-day가 실제로 없다.
- 기간·빈도를 지어내서 첫 문장을 강화하려 한다.
- 첫 DM에 링크를 넣었다.
- 같은 문구를 5명에게 1분 간격으로 연속 발송하려 한다.

### 4-5. 무응답 후속 — 최초 DM 3~4일 뒤 정확히 1회

```text
며칠 전에 불쑥 연락드렸었죠. 딱 한 번만 더 남기고 갈게요 — 목표와 D-day를 꾸준히 기록하시는 계정이라 첫 선언 자리가 잘 어울린다고 생각했어요. 언젠가 선언할 곳이 필요해지면 그때 떠올려 주시면 돼요. 답 없으셔도 더 보내지 않을게요.
```

후속에도 답이 없으면 종결한다. 같은 사람에게 세 번째 DM을 보내지 않는다.

### 4-6. 관심 표명 후 안내 — 링크와 현재 상태를 함께 보낸다

상대가 `네, 보내주세요`·`뭔가요?`·`궁금해요`라고 답했을 때만 보낸다.

```text
물어봐 주셔서 반가워요. 여기예요 —
https://haenael-ge.vercel.app/?utm_source=instagram&utm_medium=dm_outbound&utm_campaign=pretest_p0

지금 실제로 열려 있는 건 목표 선언과 전용 페이지 만들기까지예요. 정직하게 말씀드리면 결제는 붙어 있지만 토스 실키가 아직 발급되지 않아 실제 결제를 검증하지 못했고, 환전은 요청 접수와 관리자 수동 지급 구조까지 구현했지만 운영에는 아직 배포하지 않았어요.

그래서 지금 바로 실제 응원금을 받을 수 있다고 약속드리지는 않아요. 지금 오시는 분은 첫 선언자로 먼저 써보고, 이상한 점이나 아쉬운 점을 이 DM으로 말씀해 주시면 만드는 사람들이 직접 보고 고칩니다.
```

**답장 뒤 다음 액션**

1. 링크 허락 여부를 DM 원장에 기록한다.
2. 위 UTM 링크를 보낸다.
3. 상대가 선언을 만들면 `declared=Y`를 기록한다.
4. 선언 확인 후 아래 한 번만 보낸다.

```text
선언 올리신 거 봤어요. 첫 선언자 그룹에 어울리는 문장이라고 생각했어요. 쓰시다가 이상한 점이나 아쉬운 점 있으면 이 DM으로 편하게 말씀해 주세요 — 지금은 만든 사람들이 직접 듣고 고치는 시기라서요.
```

### 4-7. 거절·수신 거부

```text
알려주셔서 감사해요. 더 연락드리지 않을게요. 준비하시는 일, 잘 되길 바랄게요.
```

즉시 `do_not_contact=Y`로 기록하고 영구 제외한다.

### 4-8. 절대 하지 말 것

- 동일 문구를 자동화 도구로 대량 발송하지 않는다.
- 첫 DM에 링크를 넣지 않는다.
- 5통을 한 번에 몰아 보내지 않는다. 최소 3~5분 간격으로 손 발송한다.
- 개인화 소재를 지어내지 않는다.
- 미성년 또는 연령 불명확 계정에 보내지 않는다.
- 수신 거부한 사람에게 다시 보내지 않는다.
- 무응답자에게 후속을 2회 이상 보내지 않는다.
- `오늘만`, `선착순 마감`, `지금 안 하면` 같은 가짜 긴급성을 쓰지 않는다.
- 실결제·환전이 가능한 것처럼 말하지 않는다.
- `후원해주세요`, `가입해주세요`, `한번만 봐주세요` 같은 요청형 구걸 문장을 쓰지 않는다.
- 계정 경고·전송 실패 2건·신고 인지 중 하나라도 생기면 당일 DM·팔로우·댓글을 멈춘다.

## 5. 지금 시점 정직 고지 — 문장 단위 안전선

### 현재 상태

| 항목 | 현재 사실 | 증거 등급 |
|---|---|---|
| 목표 선언·전용 페이지 | 운영 도메인에 연결된 제품 경로가 존재 | 근거 확인 + 최근 운영 관찰 기록 |
| 결제 | 결제 코드는 붙어 있으나 토스 실키 미발급, 실제 결제 왕복 미검증 | 미검증 |
| 환전 | 요청 접수 + 관리자 수동 지급 구조로 구현 | 코드·단위/정적 테스트됨 |
| 환전 운영 | DB migration·실요청·수동 송금·PAID/REJECTED 실관찰 전, prod 미배포 | 미검증 / 미배포 |

```text
환전은 요청 접수와 관리자 수동 지급 구조까지 구현했지만 아직 운영에 배포하지 않았어요.
```
