## B. MZ 디벨롭 — 바이오/멘트 스펙트럼

### B-0. 현행 바이오가 반듯·플랫하게 읽히는 이유 (진단)

현행: `말하면 시작된다. 해낼게 🍀 / 친구의 목표 선언에, 조용히 마음을 두고 가는 곳 / 선언은 프로필 링크에서 👇`

1. **2행이 조사 완비 관형절** — "친구**의** 목표 선언**에**, 조용히 마음**을** 두고 가는 곳". 조사 3개+쉼표+수식 구조는 브로슈어 문장이다. 인스타에서 사람은 이렇게 말하지 않는다.
2. **구체물 0** — 숫자도 장면도 없이 개념어(목표·선언·마음)만 3개. 벤치마크 관찰(Bolta 2026): "2026년에 작동하는 캡션은 템플릿이 아니라 실제 사람이 쓴 것처럼 느껴지는 문장"이다.
3. **3행이 안내문 리듬** — "선언은 프로필 링크에서"는 관공서 게시판 문형.

**MZ 장치 4종 (유행어 아님 — 이 작업의 해석):** ①조사 다이어트(구어 압축) ②숫자 구체물(하트 47개) ③명사 종결·단절(다 설명 안 하는 여백이 말맛) ④브랜드명=대사 인용(친구가 "해낼게" 하면 — 서비스명이 문장 속에서 실제 입말로 살아남).

- [MZ 장치] ②숫자 구체물(브랜드 코어 넘버 47 — 피드 4번 카드와 상호참조) + ③명사 종결("클로버 하나"에서 끊기 — 설명하지 않는 여백) + 대소 대비 리듬(47개 vs 하나). [미온 근거] 돈 단어 0, 슬로건 없음, 감탄·호들갑 0 — 오히려 현행보다 건조.
- 위반 위험 지점: "하트 47개"가 맥락 없이는 ?일 수 있음 — 단 그 물음표가 피드 진입 동기(호기심 갭)로 작동하고, 핀 옆 그리드가 즉시 해소. "클로버" 신조어 선노출도 동일 구조.

**C안 — 과감 ⭐⭐⭐**
```
응원, 3초짜리 말고 남는 걸로 🍀
친구가 "해낼게" 하면 조용히 밀어주는 곳
네 목표도 말해봐 → 링크
```
- [MZ 장치] 주문 입말("~말고 ~걸로" — 카페 주문 리듬, 2026 네이티브 문형) + 반말 CTA + 기호(→). [미온 근거] 유행어·이모지 과잉 없음.
- 위반 위험 지점 3개: ①대표 카피 "말하면 시작된다"(P2-01 [stable])가 바이오에서 탈락 ②"말해봐" 반말이 톤 2층(단호/따뜻) 어디에도 없는 제3 레지스터 — 돈이 오갈 서비스의 신뢰 코드와 마찰 ③"밀어주는 곳"은 응원자 행위라, 주인공 모집 채널(인스타) 바이오에서 시점이 갈림. 채택하려면 이 셋을 감수한다는 결정 필요.

### B-2. 스레드 바이오 조정안

**현행 유지안 (안전)**: 현행 정본(`응원은 돈으로 하는 겁니다. / 휘발되는 화이팅 대신, 조용히 두고 가는 마음 🍀 / 해낼게 만드는 중 — 제작기 연재`) 그대로. 단 **"화이팅"에 따옴표 추가 권고** — story-canon §1-0의 적-인용 규칙("따옴표 인용형으로만") 정합.

**디벨롭안 ⭐⭐⭐⭐ (추천)**
```
응원은 돈으로 하는 겁니다.
"화이팅"은 3초, 클로버는 해내는 날까지 🍀
만드는 과정 전부 올림 — 해낼게
```
- [MZ 장치] 시간 대비(3초 vs 해내는 날 — 구체물) + 음슴체 "올림"(스레드 지배 문법 — 여기서만 네이티브). [미온 근거] 슬로건은 노출 허용면(킷 §0) 그대로, 장치는 리듬뿐.
- 위반 위험 지점: "올림" 음슴체는 대화층(해요/합니다) 규격 밖 — 단 스레드 한정 플랫폼 문법으로 허용할지 회장 판단 필요. 불허 시 3행만 "만드는 과정, 전부 올립니다 — 해낼게"로 교체(리듬 손실 소폭).

### B-3. 유튜브 채널 설명 — 현행 유지 추천

채널 설명은 검색 필드+롱폼이라 MZ 리듬화 이득이 낮고, 현행(§2-3)은 이미 톤 2층이 정확히 작동("하트 마흔 개는 3초 뒤에 사라지지만…"). **무변경 추천.** 굳이 맞춘다면 마지막 줄만: "선언은 아래 링크에서 시작할 수 있어요." → "선언은 아래 링크에서. 한 줄이면 됩니다." (선택).

## 셀프심문 (양방향, 위임 지정 질문)

**Q1. 22살 공부인증 유저가 "오글" 또는 "아저씨 감성"이라 느낄 지점은?**
- 오글 후보: feed-01 댓글 "여기가 시작이어도 됩니다" — 경계선이나, 권유가 아니라 허용문("~어도")이라 압박이 없어 유지. feed-05 "행운은 빌어주는 사람이 있을 때" — 어원 서사라 오글보다 세계관으로 읽힘(클로버 카드와 짝).
- 아저씨 감성 후보: **C안 "네 목표도 말해봐"** — 브랜드가 먼저 반말 거는 순간 '친한 척'이 된다. 이게 C안 추천도를 깎은 1순위 사유. 현행 바이오의 진짜 문제는 아저씨 감성이 아니라 **무인칭 브로슈어 감성**이었으므로, 해법도 반말이 아니라 입말 리듬(B안)으로 잡았다.

**Q2. 반대로 미온 규칙·정본을 깬 지점은?**
- 이모지: 전 캡션 🍀 1개 이하 ✓. 감탄사·호들갑 0 ✓. "화이팅" 자기발화 0(전부 따옴표 적-인용) ✓.
