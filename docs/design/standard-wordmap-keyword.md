## 목적

워드맵은 응원 문장을 그대로 잘라 보여주는 곳이 아니다. 사용자가 보고 “나도 저런 응원 키워드를 받고 싶다”고 느낄 수 있는 의미 단위만 보여준다. `저희가`, `클로버는`, `차례예요`, `건넬게요`처럼 조사나 서술어 어미가 붙은 문장 조각은 노출하지 않는다.

정규화 구현은 `web/src/lib/wordmap/keywords.ts`가 정본이다. 이 문서는 제품 규칙과 변경 조건을 정의한다.

## 입력과 출력 계약

| 항목 | 계약 |
|---|---|
| 입력 | `get_wordmap`이 반환한 `{ word, word_count }[]`. `word`는 짧은 한국어 응원 메시지 또는 기존 키워드다. |
| 출력 | 명사, 승인된 형용사 의미형, 감탄·격려 표현, 승인된 응원 이모지의 중복 없는 목록이다. |
| 빈도 | 한 원문에서 같은 키워드는 한 번만 센다. 서로 다른 원문에서 같은 키워드가 나오면 `word_count`를 합산한다. |
| 크기 | 합산 빈도로 기존 `s1/s2/s3` 크기 구간을 계산한다. 빈도 가중과 전체 표시 정책은 유지한다. |
| 순서 | 빈도 내림차순, 동률이면 최초 등장 순서다. |

## 추출 순서

1. Unicode NFC 정규화 후 연속 공백을 하나로 합친다.
2. `Intl.Segmenter("ko", { granularity: "word" })`로 단어 후보를 나눈다. 미지원 런타임은 Unicode 문자·숫자 정규식으로 폴백한다.
3. 문장 전체에서 승인 표현을 먼저 정규화한다. 예: `파이팅 → 화이팅`, `할수있어/할 수 있습니다 → 할 수 있어`, `대단해요 → 대단하다`, `꾸준히 → 꾸준함`.
4. 남은 후보에서 숫자, 호칭 `님`, 불용어를 제거한다.
5. 아래 조사를 가장 긴 것부터 한 번 제거한다. 제거 뒤 한 글자가 되면 단일 글자 허용 목록만 남긴다.
6. 일반 서술어 어미가 붙은 후보는 버린다. 품사를 확신할 수 없는 동사 어간을 키워드로 추정하지 않는다.
7. 최소·최대 길이, 이모지 허용 목록을 적용한다.

## 조사 제거 규칙

가장 긴 접미사를 먼저 비교한다.

- 방향·대상: `에게서`, `한테서`, `으로부터`, `에게`, `한테`, `께서`, `께`
- 비교·범위: `처럼`, `보다`, `까지`, `부터`, `마다`, `조차`, `밖에`
- 인용·선택·연결: `이라고`, `이라는`, `이라도`, `이랑`, `이든`, `든지`, `하고`, `이며`, `이면`, `와`, `과`, `랑`
- 기본 격조사·보조사: `은`, `는`, `이`, `가`, `을`, `를`, `의`, `에`, `로`, `으로`, `에서`, `도`, `만`

예: `꿈을 → 꿈`, `용기는 → 용기`, `저희가 → 저희 → 제거`, `클로버는 → 클로버 → 제거`.

## 길이와 허용 표현

- 기본 길이: 2자 이상 12자 이하.
- 1자 예외: `꿈`, `힘`, `빛`.
- 이모지 예외: `❤️`, `💚`, `👏`, `🔥`, `💪`, `🍀`, `✨`.
- 승인된 감탄·격려 표현: `화이팅`, `할 수 있어`, `잘하고 있어`, `끝까지`, `힘내`, `최고`, `응원`, `잘했어`, `축하`, `기대`, `믿어`, `함께`.
- 승인된 형용사 의미형: `꾸준함`, `멋지다`, `대단하다`, `자랑스러워`.

형용사는 일반 어미 제거로 추정하지 않고 승인된 의미형으로만 정규화한다. `예뻐요` 같은 새 표현을 자동으로 `예쁘`로 만들면 동사 조각과 같은 품질 결함이 생기기 때문이다.

## 회귀 계약

- 금지 조각 `건넬게요`, `저희가`, `차례예요`, `클로버는`은 결과에 없어야 한다.
- 의미 키워드 `용기`, `꿈`, `화이팅`, `대단하다`는 유지해야 한다.
- 정규화 후 결과가 0건이면 기존 워드맵 빈 상태를 보여준다.
- 13개 이상의 키워드도 접거나 자르지 않고 전부 표시한다.
- 빈도 가중 크기 `s1/s2/s3`는 정규화 후 합산 빈도로 계산한다.
