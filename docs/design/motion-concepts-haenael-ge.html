해낼게 모션 용어·개념 정리

회장 질문(2026-10-02): 용어를 UI 모션이라 하면 되나, 인앱 버튼 컨페티도 UI 모션인가, 로딩·랜딩에서 시선 잡는 건 뭔가, 리모션·모션그래픽은 영상 전용인가, 로딩·동적화면은 GIF 쓰나. 표준 출처(LottieFiles, NN/g, Wikipedia)로 확인해 정리했습니다.

1. 큰 지도: 용어 위계

모션 디자인(motion design) = 화면 위 모든 움직임을 아우르는 큰 우산입니다. 그 아래로 성격이 다른 두 갈래가 있습니다.

  • UI 애니메이션(UI animation): 제품 UI 요소에 움직임을 줘 상호작용을 돕는 것. 앱 "안"의 움직임 전반.
  • 모션 그래픽(motion graphics): 로고·텍스트·도형 등 그래픽으로 "이야기를 전하는" 움직임. 주로 영상·광고·인트로. 제품 조작과 무관한 서사 연출.

그리고 UI 애니메이션 안에 특히 작은 단위가 마이크로 인터랙션(microinteraction)입니다. 버튼 탭, 토글, 좋아요처럼 유저 행동에 즉시 반응하는 작고 기능적인 피드백.

2. 질문별 정확한 답

Q. 용어를 "UI 모션"이라고 하면 됨?

됩니다. UI 모션 = UI 애니메이션으로 통용됩니다. 더 정확히는, 유저 행동에 반응하는 작은 것은 마이크로 인터랙션, 화면 전체의 전환·등장은 UI 애니메이션/트랜지션이라 부르면 깔끔합니다. 지금 프로토의 화면 전환 fade, 카드 떠오름이 여기에 해당합니다.

Q. 앱 안에서 버튼 눌렀을 때 터지는 컨페티도 UI 모션인가?

예. 인앱 컨페티는 마이크로 인터랙션(보상·축하 피드백)의 한 종류이고, 따라서 UI 모션입니다. 영상(모션 그래픽)이 아니라 앱 안에서 실시간으로 그려지는 연출입니다. 구현은 CSS·JS 입자, 또는 Lottie·Rive 애니메이션으로 합니다. 참고로 해낼게는 결정 D-003("지갑은 조용하게")과 브랜드 "조용히" 때문에 폭죽형 컨페티는 배제하고, 클로버가 은은히 떠오르는 절제된 보상 연출을 씁니다.

Q. 로딩이나 랜딩에서 움직이며 시선 잡는 건 뭐라고 부르나?

  • 로딩 중 기다림 연출: 로딩 애니메이션(스피너, 프로그레스, 또는 콘텐츠 자리를 미리 깔아주는 스켈레톤 로더).
  • 랜딩에서 시선을 잡는 큰 움직임: 히어로 애니메이션(hero animation), 스크롤에 반응하면 스크롤 트리거 애니메이션, 가만히 둬도 은은히 도는 건 앰비언트/루프 애니메이션이라 합니다.
회장이 보내주신 스레드 예시 같은 "살아 움직이는 랜딩"은 보통 히어로 애니메이션(루프)입니다.

Q. 리모션·모션그래픽은 영상 렌더링할 때만 쓰는 용어인가?

  • Remotion(리모션): React 코드로 영상(mp4 등)을 찍어내는 도구입니다. 결과물이 동영상 파일이라, 앱 안에서 실시간으로 반응하는 UI 모션에는 안 씁니다. 유튜브·광고·SNS 영상 자동 생성 쪽입니다.
  • 모션 그래픽: 개념은 영상 전용이 아닙니다. 다만 "제품 조작과 무관한 서사형 움직임"을 뜻해 실무에선 영상·인트로에 주로 씁니다. 앱 안에서 쓰고 싶으면 보통 영상이 아니라 Lottie로 넣습니다.
정리: 앱 안의 반응 = UI 모션(CSS·Web Animations·Lottie·Rive), 영상 제작 = 모션 그래픽·Remotion. 둘은 도구와 결과물이 다릅니다.

Q. 로딩 화면이나 동적 화면은 GIF로 하나?

현대 앱·웹에서는 GIF를 권장하지 않습니다. GIF는 용량이 크고(같은 연출이 Lottie의 약 4배), 256색 한계로 그라데이션이 뭉치고, 래스터라 확대하면 흐려지고, 부분 투명도가 없습니다. 대신:
방식무엇쓰는 곳
CSS · Web Animations코드로 그리는 가벼운 움직임전환, 버튼 반응, 간단한 등장(지금 프로토)
Lottie (dotLottie)벡터 애니를 JSON으로. 수십 KB, 선명, 재색칠 가능로딩 애니, 랜딩 히어로, 축하 연출
Rive상태머신 있는 인터랙티브 벡터 애니유저 입력에 반응하는 복잡한 모션
mp4 · webm영상배경 영상, 실사 연출
GIF구형 래스터이메일·채팅 등 Lottie 안 되는 곳만
해낼게 권장: 지금의 전환·보상은 CSS로 충분하고, 랜딩 히어로나 로딩처럼 "조금 더 살아있는" 연출이 필요하면 Lottie를 얹는 게 정석입니다.
