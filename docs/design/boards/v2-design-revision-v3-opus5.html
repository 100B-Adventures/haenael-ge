해낼게 V2 디자인 개정 3차 — 지적하신 여섯 가지

왼쪽이 지난 판, 가운데가 이번 개정, 오른쪽이 실제 녹화한 모션입니다. 화면마다 아래에서 승인·수정·반려를 고르고 메모를 적으시면 입력하는 대로 저장되고, 위 메모·선택 전체 복사 버튼 하나로 전부 꺼내집니다.

이번 판에서 고친 것과, 왜 그렇게 고쳤는지

1. 목표 관리 버튼이 CSS 없이 렌더된 건. 마크업 부모는 .goal-actions 인데 스타일은 .gfoot .gmanage 로만 선언돼 있었습니다. class 선언 여부만 보는 검사로는 안 잡히는 종류라, 렌더한 뒤 실제로 규칙이 걸렸는지 보는 검사기를 하네스에 넣고 23종을 전부 0 으로 만들었습니다.

2. 배너. 배너는 그 목표를 시각화하는 자리라는 정의를 결정 원장에 박고(D-028-A), 단색 그라데이션 6종을 폐기했습니다. 목표 성격별 실사 8종을 만들어 카카오 선물하기 메시지 카드처럼 가로로 넘겨 고르게 했고, 직접 업로드는 유지하며, 아무것도 안 고르면 목표 문장에서 성격을 읽어 자동으로 배정합니다.

3. 버전. 파일명을 올리지 않았습니다. v3 는 승인 세대 표기이고 작업 횟수가 아니라는 규칙을 하네스 표준으로 만들었습니다(prototype-versioning.md). 같은 세대 안의 개정이므로 같은 파일을 고치고 이력만 쌓았습니다.

4. 문구. 전송 경로·폴백 설명과 알림 채널 배지를 전부 걷어냈고, 없는 것을 설명하는 "금액도 순위도 없어요" 를 다섯 화면에서 지웠습니다. 금지 항목으로 UX writing 기준에 등재했습니다.

5. 모션. 따로 모아 두지 않고 화면 캡처와 같은 행, 같은 짝 안에 넣었습니다.

랜딩

비회원이 공유 링크 없이 처음 닿는 화면. 하단탭 유지(D-025-A).

이번 판 변경점

  • 변경 없음. 이번 지적 6건에 해당 사항이 없습니다. 대조를 위해 그대로 싣습니다.

홈 (내 목표)

실배포 (receiver)/me 계승. 목표 카드 목록과 클로버 잔액.

이번 판 변경점

  • 목표 카드 배너를 실사로. 단색 그라데이션 띠는 그 목표가 무엇인지 아무것도 말하지 않습니다. 세 카드를 각각 공부·러닝·자격증 사진으로 바꿨습니다."해낼게 배너의 의미가 뭐야 목표 관련 이미지를 시각화하는거지? 정의안되어있으면 보여줄걸 단색이면 좀 그렇지 않냐?"
  • 지난 목표 카드의 인라인 opacity 를 CSS 규칙으로. 마크업에 흩어진 스타일을 규칙으로 모으는 것이 이번 CSS 검사의 취지입니다.

해낼게 관리

회원의 최상위 관리면. 하단탭 유지이므로 전역 푸터를 깔지 않습니다.

이번 판 변경점

  • 목표 관리 버튼이 CSS 없이 렌더되던 것을 고쳤습니다. 마크업 부모는 .goal-actions 인데 스타일은 .gfoot .gmanage 로만 선언돼 있어, 브라우저 기본 버튼이 그대로 보였습니다. 선택자를 실제 부모에 맞추고 위계를 정했습니다: 응원 인원은 윗줄, 아래에 보조(목표 관리, 테두리)와 주(응원 링크 공유, 채움)를 같은 폭 44px 로 나란히."해낼게 관리에서 목표관리 버튼은 왜 저따위로했고 ... 저런 쓰레기 css 없이 프로토타입이랍시고 올린 이유"
  • 알림 문구에서 전송 경로를 걷어냈습니다. "카카오 알림톡으로 먼저 보내고, 실패하면 앱 알림으로 보내요" 를 "응원이 오면 알려드려요" 한 줄로 줄였습니다. 알림 목록의 채널 배지(알림톡 ✓ / 앱 알림)도 같은 이유로 뺐습니다."응원 도착 알림에 잡 소리가 추가된 이유도 해명해라"
  • 배너를 이 화면에서도 바꿉니다. 배너를 탭하면 프리셋 선택기가 열립니다. 캡션도 소유자 이름이 아니라 목표 문장("토익 900 해낼게")으로 바꿨습니다. 배너는 사람이 아니라 목표를 시각화하는 자리이기 때문입니다."배너사진은 너는 저게 이쁘다고생각하냐?"
  • "금액도 순위도 없이, 응원 메시지와 도착 시각만 보여요" 를 지웠습니다. 없는 것을 설명하지 않고 화면이 그렇게 생기게 뒀습니다."금액도 순위도 없어요 이런 좃같은 ux writing 한 이유도 해명해"

목표 관리 (상세)

응원자 명단·워드맵·환전을 가진 목표 단위 관리 화면.

이번 판 변경점

  • 배너 고르기 신설. 프리셋을 그라데이션 6종에서 목표 성격별 실사 8종으로 바꾸고, 가로로 넘겨 고르면 위 배너가 즉시 바뀝니다(카카오 선물하기 메시지 카드 방식). 직접 업로드는 그대로입니다. 오른쪽 모션에서 실제로 눌러 바뀌는 것을 보실 수 있습니다."카톡 선물하기 보면 메세지있잖아 그런거처럼 선택할수도 있게 해야지"
  • D-day·진행 중 칩 정렬. .gd-hero .gtop 에 규칙이 없어 칩 두 개가 흩어져 있었습니다.
  • 워드맵·응원자 명단의 "금액도 순위도 없어요" 를 뺐습니다. 크기 위계 설명 한 줄만 남겼습니다.

온보딩 (목표 만들기)

목표를 쓰고 배너를 고르는 자리. 비회원도 여기까지 옵니다.

이번 판 변경점

  • 목표를 쓰는 자리에서 배너를 고릅니다. 실사 8종으로 바꾸고, 고르지 않으면 쓴 목표 문장에서 성격을 읽어 자동 배정합니다(빈 배너나 단색으로 시작하지 않습니다). 자동으로 고른 칸에는 "자동" 표시가 붙습니다."정의안되어있으면 보여줄걸 단색이면 좀 그렇지 않냐?"

공개 목표

비회원이 공유 링크로 도착하는 화면.

이번 판 변경점

  • 배너 자산 통일. 지난 판에서 쓰던 임시 커버를 이번 프리셋 세트로 맞췄습니다. 캡션도 목표 문장으로 바꿨습니다.

친구

응원하면 친구가 됩니다(D-024).

이번 판 변경점

  • "금액도 순위도 없이 친구의 목표와 응원 소식만 보여요" 를 지웠습니다."금액도 순위도 없어요 이런 좃같은 ux writing"
  • 친구 행 오른쪽 chevron 을 정렬했습니다. .fr .rel .mp-go 에 규칙이 없어 맨 글자(›)로 렌더되고 있었습니다.

친구 상세

친구 한 명의 목표와 받은 응원.

이번 판 변경점

  • 배너 자산 통일. 그 외 변경 없음. 지난 판에 노출한 응원 워드맵은 그대로입니다.

업적

DB 집계로 반증 가능한 세 지표만 씁니다(D-022).

이번 판 변경점

  • 변경 없음. 지난 판의 메달 진열대 재설계를 유지합니다. 모션을 다시 녹화해 함께 싣습니다.

응원 워드맵 (전체 보기)

받은 응원 전부 표시. 하단탭 유지.

이번 판 변경점

  • 설명 세 줄을 한 줄로. "받은 응원은 전부 보여요 · 같은 단어가 쌓일수록 크게 자라요 / 금액도 순위도 없어요" 를 "받은 응원이 전부 여기 있어요" 로 줄였습니다. 크기 위계 설명은 그 개념이 처음 등장하는 화면(목표 관리) 한 곳에만 둡니다."금액도 순위도 없어요 이런 좃같은 ux writing"
  • 떠다니는 배치 유지. 한 줄로 눕지 않는 것을 이번 녹화로도 확인하실 수 있습니다."한줄로 하지말라고 말했는데 다 씹네"

환전

돈이 움직이는 단일 거래. 하단탭 숨김.

이번 판 변경점

  • 변경 없음. 수수료 공식과 환전 잠금은 손대지 않았습니다.
