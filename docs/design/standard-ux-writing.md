# 해낼게 UX writing 기준

## 목표

사용자가 한 번 읽고 “지금 무엇이 있고, 무엇을 하면 되는지” 알게 쓴다. 제품이 감정을 대신 말하지 않고, 실제 사람의 목표와 응원 메시지가 감정을 만든다.

## 용어 정본

| 개념 | 쓰는 말 | 쓰지 않는 말 |
|---|---|---|
| 목표를 시작한 이유 | `WHY` | `왜요`, `마음`, `열리는 것` |
| 개인 관리 허브 | `해낼게 관리` | `마이페이지`, `내 공간` |
| 상호 응원 관계 | `친구` | `연결된 친구`, `서로 응원하는 친구` |
| 응원 메시지 시각화 | `응원 워드맵` | `마음 구름`, `응원의 자리` |
| 목표 상태 | `진행 중`, `완료`, `종료` | `여정 중`, `피어나는 중` |
| 공유 행동 | `공유하기`, `응원 링크 복사` | `마음을 퍼뜨리기`, `세상에 열기` |

## 문장 규칙

1. 동작은 동사로 쓴다. `환전 신청`, `공유하기`, `친구 초대하기`처럼 사용자가 누른 뒤 벌어질 일을 버튼에 적는다.
2. 모호한 명사화를 쓰지 않는다. `열리는 것들`, `이어지는 자리`, `함께함의 기록`처럼 화면 결과를 예측할 수 없는 표현은 금지한다.
3. 같은 데이터에는 같은 말을 쓴다. 공개 목표와 관리 화면에서 목표 이유는 모두 `WHY`다.
4. 한 문장에는 한 정보만 둔다. 조건과 결과가 다르면 문장을 나눈다.
5. 사용자 감정을 단정하지 않는다. `벅찬 마음이 들 거예요` 대신 `응원 메시지가 여기에 쌓여요`처럼 관찰 가능한 결과를 쓴다.
6. 빈 상태는 현재 상태, 가능한 이유, 다음 행동 순서로 쓴다. 예: `아직 친구가 없어요. 친구를 초대하거나 서로 응원하면 친구가 돼요.`
7. 오류는 책임 추궁 없이 결과와 복구 행동을 쓴다. 예: `설정을 저장하지 못했어요. 다시 시도해 주세요.`
8. 금액·계좌·수수료는 법적·기술적 표준 용어를 그대로 쓴다. 공식과 마스킹은 `wiki/거버넌스/결정.md`의 정본을 바꾸지 않는다.

## 줄바꿈 규칙

- 제목은 `word-break: keep-all`을 기본으로 하고, 긴 제목은 의미 단위에서 줄바꿈되게 한다. 글자 중간 강제 개행은 금지한다.
- 버튼과 탭 라벨은 한 줄을 유지한다. 390px에서 잘리면 문구를 줄이거나 레이아웃을 고친다.
- 라벨과 값은 같은 줄에 억지로 붙이지 않는다. `WHY`는 라벨 한 줄, 이유는 다음 줄로 구분한다.
- 한 문장에 쉼표로 세 항목 이상 넣지 않는다. 목록이나 별도 행으로 나눈다.
- 사용자가 입력한 긴 닉네임과 목표 제목은 레이아웃을 밀지 않게 말줄임 또는 자연스러운 다중 줄을 적용하고, 원문은 `title` 또는 상세 화면에서 확인할 수 있게 한다.

## 화면 적용 예시

| 이전 | 변경 | 이유 |
|---|---|---|
| `도경이를 응원하는 사람으로서 열리는 것들` | `도경의 해낼게` | 화면 대상을 즉시 말한다. |
| `오래 함께한 응원자에게만 조용히 열리는 자리예요` | `응원한 친구에게만 근황과 응원 기록을 보여줘요` | 공개 범위와 보이는 정보를 구체적으로 말한다. |
| `마이페이지` | `해낼게 관리` | 이 화면의 1급 목적이 목표·응원·공유 관리임을 밝힌다. |
| `왜요?` | `WHY` | 공개 목표와 동일한 개념을 동일한 라벨로 쓴다. |
| `연결된 친구`, `서로 응원` | 삭제 | 친구가 된 조건을 행마다 반복하지 않는다. |

## 출고 체크

- 탭·버튼을 읽으면 눌렀을 때 결과를 예측할 수 있는가.
- 같은 개념이 다른 화면에서 다른 말로 쓰이지 않았는가.
- 은유를 지워도 의미가 더 선명한가. 그렇다면 은유를 지운다.
- 390px에서 이름, 제목, 버튼 라벨이 글자 중간에서 깨지지 않는가.
- 빈 상태, 오류 상태, 긴 문자열 상태가 모두 다음 행동을 제공하는가.

## 반례 점검

- 모든 감정 표현을 지우면 해낼게의 따뜻함도 사라질 수 있다. 그래서 제품 안내는 구체적으로 쓰되, 실제 응원 메시지와 하트 같은 정서 요소는 유지한다.
- 영어 `WHY`는 한국어 맥락에서 이질적일 수 있지만 이미 공개 목표의 승인 라벨이며, 같은 개념 통일이 이번 지시의 우선 조건이다.
