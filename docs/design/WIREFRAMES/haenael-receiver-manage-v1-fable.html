[재방문 시나리오별 경로 — dead-end 0]

A. 인스타 바이오 자기링크 탭(가장 흔함)
   /g/[slug] ─(본인 세션)→ owner bar "내 해낼게 관리" → /home
             ─(세션 없음)→ 친구용 화면 → 하단 "내 목표가 있으신가요? 로그인" (footer, subtle)
                            → 카카오 로그인 → 본인 확인 → /home

B. 북마크·주소 직접입력  /home ─(세션 有)→ 홈  ─(세션 無)→ 카카오 로그인 → /home
C. 루트 / 진입           / ─(세션 有 + 목표 有)→ /home 리다이렉트
                          ─(세션 有 + 목표 無)→ /onboarding
                          ─(세션 無)→ ① 랜딩(landing-final) 그대로
D. 알림(카카오 알림톡) 링크 → /home 직행(세션 없으면 로그인 후 /home)

edge: 로그인했지만 남의 /g/[slug] → owner bar 없음(친구용 그대로)
      본인 목표 삭제 후 /home → "종료된 목표" + 새 목표 만들기(/onboarding)
      세션 만료 상태로 owner 기능 접근 → 화면 1 error 상태(재로그인, draft·열람 유지)
