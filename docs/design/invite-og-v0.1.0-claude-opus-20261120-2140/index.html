A 사진 전면 (추천)250px 말풍선에서 목표 문장이 19px 상당으로 가장 크고, 사진이 칸 전체를 채워 회색 텍스트 말풍선 사이에서 가장 먼저 눈에 띕니다. 친구 얼굴 칩과 "12명이 응원 중"이 사회적 증거, D-23 이 마감 긴장을 만듭니다(셋 다 실제 값).커버 사진은 프리셋 8장을 많은 사람이 같이 씁니다. 원본이 780×440 이라 1200 폭에서 약간 흐립니다. 구현 때 프리셋을 1600px 로 다시 내보내야 합니다. 사용자 사진 커버면 이 약점은 사라집니다.
B 선언문지금 기본 이미지(종이색·검은 굵은 글씨·워드마크)를 그대로 잇습니다. 따옴표 문장이 "선언"을 직접 보여 주고, 숫자 두 개가 GitHub 저장소 카드처럼 읽힙니다.말풍선 크기에서 사진이 작아 첫눈에 덜 끌립니다. 목표가 짧으면 왼쪽 아래가 비어 보입니다.
C 응원 티켓초록 바탕이 카톡방에서 가장 튀고, 마감 도장이 재미를 줍니다. 얼굴이 가장 큽니다.요소가 많아 250px 에서 목표 문장이 15px 상당으로 작아집니다. 긴 목표는 두 줄에서 일찍 잘립니다.

Satori 규칙cards.js 의 모든 상자는 flex 와 absolute 위치만 씁니다. grid·의사요소 없음. 제목 줄바꿈은 wordBreak: keep-all, 넘침은 서버의 fitTitle() 이 글자 크기 3단(예: 92/80/68)을 고르고 그래도 넘치면 말줄임으로 자릅니다. 이름은 8자 넘으면 말줄임.
상태 규칙응원 0명 = "첫 응원을 기다려요"(0명이라고 쓰지 않음). 마감일 없음 = D-day 칸 숨김. 마감일 오늘 = "오늘 마감". 마감 지남·달성 상태는 이번 범위 밖이며 같은 칸에 "해냈어요"를 넣는 방식을 권합니다. 프로필 사진 없음 = 이름 첫 글자 원(빈 상자 금지, 23번 레퍼런스가 실패 사례).
