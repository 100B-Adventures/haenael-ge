> CDP(Playwright connectOverCDP)로 **그대로** 읽어온 것이다. 요약·의역하지 않았다.
> 왜 이 파일이 생겼나: 보드에 메모칸은 넣었는데 **일괄 복사 수단을 안 넣어서** 회장이 입력한 내용을 꺼낼 수 없었다.
> 회장 "메모남겼으면 일괄 복사하도록 선택하는거 하네스에 없었냐? 지금 브라우저에 다 입력해놨는데 니가 좃같이 안넣어서 복사를 못하는 상황".

## 이 메모에서 확정되는 작업

- D-027-A 랜딩: 동적 모션이 **보드에서 보이지 않는다.** 정지 캡처만 올려서 모션을 판단할 수 없게 만든 것이 문제다. 모션은 GIF 또는 영상으로 보여준다(하네스 과제).
- D-027-B 공개 목표: 목표 제목에서 **'해낼게'를 다른 색으로 강조**(이전 배포 처리). 신고 버튼 위치·간격 구조 재설계.
- D-027-C 해낼게 관리: 푸터가 **아직 남아 있다**(푸터 제거가 이 화면에 적용 안 됨). 로그아웃 위치, 알림 토글 UI, 상세 관리 진입 경로 부재, 배너 사진 품질 전부 재작업.
- D-027-D 업적: 이미지가 업적 화면에 맞지 않는다. 동적 모션 없음, 아이콘 품질 미달. 재작업.
- D-027-E 응원 워드맵: **한 줄로 하지 말라는 지시를 반복해서 어겼다.** 워드맵 배치를 떠다니는 형태로 다시 만든다.
- D-027-F 친구 상세: 응원 워드맵이 보이지 않는다. 노출한다.
- D-027-G 하네스: 결정 보드에 **메모·선택 일괄 복사 버튼**을 필수로 넣는다. 린트가 없으면 반려한다.
