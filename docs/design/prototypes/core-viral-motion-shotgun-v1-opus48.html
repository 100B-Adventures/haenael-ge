세 성격 축(용어 = motion-concepts-haenael-ge.html 표준) · A 절제(UI 트랜지션 페이드업) 조용한 응원 톤, decel, 느림 / B 스프링 바운스(마이크로 인터랙션) overshoot 튕김 확실히 / C 클로버 파티클(마이크로 인터랙션·보상) 잎이 또렷이 떠오름. 컨페티 폭죽은 D-003 때문에 배제, 금액·랭킹 0.

MOMENT 1 · 초대한 친구가 합류하는 순간 (바이럴 루프가 닫히는 절정)

"윤도경님이 초대를 받고 들어왔어요" 합류 카드 등장. 심리 = 관계 형성 방향 안내 + 조용한 보상. 용어 = 마이크로 인터랙션(보상 피드백).

MOMENT 2 · 함께 응원하는 친구가 차오르는 순간 (정서 절정)

아바타 스택 등장 + 인원수(13명) 카운트업. D-003: 금액·랭킹 없이 인원수만. 용어 = UI 애니메이션 + 마이크로 인터랙션(카운트).

MOMENT 3 · 첫 랜딩 진입 시선 (히어로 애니메이션)

앱/웹 첫 진입에서 브랜드·단어가 떠오르며 시선을 잡는 연출. 용어 = 히어로 애니메이션(C는 앰비언트 루프 포함).

MOMENT 4 · 로딩 대기 (스켈레톤 · 로딩 애니메이션)

데이터 불러오는 동안의 대기 연출. 용어 = 스켈레톤 로더 / 로딩 애니메이션. 빈 화면 방지 + 체감 대기 단축.
