개정에서 바뀐 점 (v1.1 → v2)

워드맵을 프리뷰 장식에서 히어로로 승격.
회장 요구 "단어지도 디자인을 특히 아름답게" 반영 · 3단 size/weight/opacity에 조용한 드리프트 모션(6s, prefers-reduced-motion 존중)을 얹어 "쌓이는 구름"을 살아있게. 정적 프리뷰(page.tsx:71-122)의 절대배치 8단어 → flex 구름 12단어로 확장.
i18n KO/EN 토글 신규.
회장 요구 "다국어 지원으로 해외 광고" 반영 · 상단 언어 토글로 슬로건·훅·CTA·워드맵 단어셋이 동시 전환. 영문 단어도 Pretendard Latin으로 자간 -0.4px 조여 아름답게 렌더.

심리·설득 근거

궁금증 갭: "응원은 돈으로 하는 겁니다" + "그게 무슨 말이냐면 ↓" 로 스크롤/탐색 욕구 유발(page.tsx 주석 근거 계승).

Zeigarnik: 반쯤 찬 워드맵 = 미완성 긴장 → "내 것도 채우고 싶다". 사회적 증거 프리뷰: 먼저 쌓인 응원 결과를 먼저 보여줌.

CTA 욕구: "시작하기"는 결과를 못 말하는 무의미 라벨 후보라 clover 단색 무게로 시각 1순위를 확보하고, 눌렀을 때 온보딩 선언(문턱 낮음)으로 바로 연결.
