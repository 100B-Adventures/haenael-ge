## 2. 회장 질문에 대한 답 — "수수료 정하고 화면 고치고 환전 확인하면 끝인가?"

**대체로 맞다. 다만 두 가지가 빠져 있다.**

### 이번 세션에 끝낼 것 (회장이 짚은 3개)

| 순서 | 할 일 | 왜 지금인가 |
|---|---|---|
| ① | 수수료 요율 확정 | 회장 결정만 남음 |
| ② | 약관·환전 화면·DB 세 곳 숫자 맞추기 | **지금 셋이 서로 다른 값을 말한다** |
| ③ | 환전 1회 실왕복 확인 | 신청 이력 0건. 돈이 실제로 도착한 적 없음 |

### 회장이 빠뜨린 것 (새 기능이 아니라 이미 벌어진 부채)

| 항목 | 왜 미룰 수 없나 |
|---|---|
| **인앱 알림 중복** | 응원 1건에 알림 2개가 쌓인다. **이미 운영에 배포된 상태**라 지금 사용자가 겪는다. 수정 범위는 작다 |
| **마이그레이션 이력 불일치 12건** | `20260720~20260731` 12건이 미적용인데 그 이후 것들이 적용돼 있다. 다음에 DB를 건드릴 때 사고가 난다. 이번에 환전 관련 DB를 고치므로 **지금 밟게 될 지뢰다** |

### 다음 세션으로 넘길 것 (새 내용)

| 항목 | 근거 |
|---|---|
| 초대 등급제 실제 구현 | 인프라 0에서 시작. 사용자 2명인 지금 만들 실익 없음 |
| 등급별 UI 선택권 | 회장 확정: 다음 버전 스프린트 |
| 응원자 대상 알림 | 구조 변경 필요(비로그인 응원 문제) |
| 송금 재원 계좌 분리 | 회장 판단 + 법률 자문 영역 |
| 사업소득 원천징수 성격 정리 | 세무 확인 필요 |
| 파이프라인 현행화 | 위생 작업, 급하지 않음 |
| 죽은 코드 정리 | 위생 작업, 급하지 않음 |

## 3. 정정 — 이전 보고에서 틀렸던 것

| 이전 서술 | 실제 |
|---|---|
| "계좌 90일 파기 작업 미등록" | **등록돼 있고 가동 중.** `purge-expired-cashout-accounts`, 매일 03:17 실행, 활성 |
| 10% 요율 실수령 25,500원 | **25,819원.** 부가세를 이중 계산했음 |
| "수수료 5%도 과하다" | 비교군을 배관 사업자로 잘못 잡음. 목적지 플랫폼 기준으로는 15~20%가 낮은 편 |

같은 조회에서 `expire-stale-cheer-payments`(10분마다)도 정상 가동 중임을 확인했다.

## 5. 현재 어긋나 있는 세 곳

| 위치 | 지금 뭐라고 하나 |
|---|---|
| 약관 | 수수료 5% + 부가세 별도 |
| 환전 화면 | "플랫폼 수수료 없이" |
| DB | 수수료 자리에 0 |

요율을 뭘로 정하든 이 셋을 같은 값으로 맞춰야 한다. 사용자에게 유리한 방향으로 동작 중이라 금전 피해는 없으나, 약관과 화면이 정반대를 말하는 것 자체가 표시 규제상 위험이다.

## 6. 미검증으로 남은 것

- **환전 실왕복 전무.** 신청 이력 0건. 신청·관리자 지급·입금 어느 것도 실제로 돌아간 적 없다
- 관리자 화면 실사용 미확인
- 콜드스타트 실측치 없음
