# V2 디자인 개정 5차 판정표 (회장 지적 11건 전수 · D-031)

대상 프로토타입: `docs/design/prototypes/social-viral-loop-v3-opus5.html`
파일명은 그대로 둔다. `v3` 은 승인 세대 표기이고 작업 횟수가 아니다 (`~/.claude/standards/artifact-stamp.md` §1).

이번 판은 **회장이 프로토타입을 직접 보고 짚은 결함 11건**을 수용 기준으로 한다.
11건 중 다수가 텍스트 넘침과 고아 줄바꿈이고, 회장 표현은 "이런 좃같은 기본적인 실수 내 눈에 안띄게 안하냐" 다.
그래서 이번 판의 중심은 개별 수정이 아니라 **같은 종류가 다시 못 나오게 하는 장치**다(§3·§4).

## 2. 원인분석: 왜 "얘기했던게" 또 누락됐나 (회장 지시 #4)

**짧은 답: 규칙의 정본이 사람의 기억 안에 있었다.**

법적 고지 노출은 2026-10-16 에 결정(D-027-C)되고, 10-17 에 전 화면 표(D-030-B)까지 만들어졌다.
그런데 그 표는 **문서 한 곳과 각 화면 마크업 여러 곳**에 흩어져 있었고, 코드에는 그 표를 아는 주체가 없었다.
그래서 화면을 고칠 때마다 사람이 기억으로 다시 판단했고, 한 판에 한 화면씩 어긋났다.

| 판 | 어긋난 자리 | 회장 지적 |
|---|---|---|
| v1 | 전 화면 전역 푸터 | "하단탭 밑에 푸터가 있으니" (D-026-B) |
| v2 | 해낼게 관리에 잔존 | "푸터 없앤다며? 여기엔 왜있고" (D-027-C) |
| v3 | 환전에 잔존 | "여기서 사업자푸터 보여주다가 이제는 그냥 다 조져버렸녜?" |
| v4 | 공개 목표에 상시 노출 | "필요할때만 보이도록 하기로 하지 않았냐?" |

**같은 결정이 네 번 새로 내려진 것이지, 한 번도 집행된 적이 없다.** 사람의 기억을 규칙 집행자로 두는 한 다섯 번째가 난다.

**조치 = 표를 코드로 만든다.** `LEGAL_EXPOSURE` 상수가 이제 그 표이고 `renderLegalFoot()` 가 그 표대로만 그린다.
표에 없는 화면은 `.legalfoot` 마크업이 있어도 렌더 시점에 제거된다. **기억이 아니라 데이터가 집행한다.**

같은 형태의 결함이 이번 판에 셋 더 있었고 전부 같은 처방을 했다.

| 결함 | 종전 집행자 | 새 집행자 |
|---|---|---|
| 법적 고지 노출 | 문서 + 사람의 기억 | `LEGAL_EXPOSURE` 데이터 |
| 모션 목록의 진실성 | 손으로 쓴 고정 표 | 선택자 필터 + `getAnimations()` 실측 표시 |
| 텍스트 넘침·고아 줄바꿈 | 사람 눈 | `scripts/qa/lint-prototype-overflow.mjs`(0건 = 출고 조건) |
| 배너 업로드 복귀 경로 | 하드코딩된 화면 id | 들어온 화면을 기억하는 `buFrom` |

## 3. 신설 하네스: 넘침·고아 줄바꿈 린트 (회장 지시 #7 "하네스 걸어라")

`scripts/qa/lint-prototype-overflow.mjs`

| 항목 | 내용 |
|---|---|
| 검출 A · 가로 넘침 | `element.scrollWidth > element.clientWidth`(+1px 허용). 의도적 가로 스크롤(`overflow-x:auto/scroll`)은 제외. `overflow:hidden`(잘림)은 **글자가 직접 들어 있을 때만** 결함으로 센다 — 관리자 `88,964원` 이 그 경우였고, 그림자용 가상요소나 `scale` 된 사진이 잘리는 건 의도다 |
| 검출 B · 고아 줄바꿈 | `Range.getClientRects()` 로 실제 줄박스를 재고, 2줄 이상인데 **마지막 줄 폭 28px 미만**이면 결함. 글자 크기가 다른 인라인 자식(21px 제목 끝의 13px 연필)이 같은 줄임을 알도록 **세로 겹침**으로 줄을 묶는다 |
| 범위 | 제품 화면(`section.screen .frame`)만. 검수 셸(우측 패널·콘솔·모션 도크)은 제품이 아니므로 제외. 좌측 플로우맵은 회장이 직접 지적했으므로 `--shell` 로 따로 본다 |
| 측정 조건 | 진입 모션이 끝난 뒤 `getAnimations().cancel()` 로 **정지시킨 다음** 잰다. 카운트업 bump(`scale 1.18`)나 부유 루프의 transform 이 스크롤 영역을 순간적으로 넓히는 것은 레이아웃 결함이 아니다 |
| 소요 | 25화면 전수 **23초** (요구 2분 이내) |
| 출고 조건 | **0건** |

```
화면 25개 · 가로넘침 0건 · 고아줄바꿈 0건 · 검수셸(플로우맵) 넘침 0건
판정: PASS (0건)
```
