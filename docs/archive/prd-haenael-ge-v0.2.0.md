## 0. 제품 한 줄

**친구가 "○○ 해낼게" 목표를 선언하면, 다른 친구가 그 목표에 *조용히 돈으로*(하트/클로버) 응원하고 가는 도네이션 플랫폼.** 카톡 선물하기의 양쪽 피로(뭐 보낼까 / 감사답장)를 **비동기·무부담**으로 없앤 "조용한 마음표현". 받은 사람이 모인 클로버를 **모이면 환전**할 때 수수료 = 메인 BM(별풍선·투네이션형 가상화폐).

## 1. One Thing (요약 — 정본: one-thing.md)

> ## **"친구가 선언한 목표에, 조용히 돈으로 응원하고 간다."**

- 두 목소리: 주인공 **"나 ○○ 해낼게"**(선언=액자) ↔ 친구 **조용히 하트/클로버 💸**(비동기 마음표현)
- 핵심 에토스 = **조용히 = 비동기·무부담**(익명 아님). 주는 쪽은 "뭐 보낼까" 고민 0, 받는 쪽은 "감사답장" 의무 0. 인사하고 싶으면 비동기로 한 줄.
- 함정답(reject): 투네이션 클론 / 셋로그·Strava 클론 / 크라우드펀딩 / 내기·베팅 / 자선모금 → 상세 one-thing.md.
- **wedge = 오직 '돈'**: 무결제 기록+공유는 셋로그/Strava 점령. 차별점은 지인 목표에 거는 *실제 후원*뿐.

## 3. 코어 메커니즘 — "조용한 마음표현" (v0.2.0 정밀화)

```
[주인공]  인스타 바이오에 linktree식 링크 박음
            └▶ 해낼게 페이지: "나 편입 평점 4.0 해낼게" + 일정 + 왜(이유)   ← 목표·왜만. 매일 인증 강제 X
                                         │
[친구]  인스타 눈팅 ──링크 클릭──▶ 페이지 도착
            └▶ (부담 0) 조용히 하트/클로버 결제  +  원하면 한 줄 응원(비동기)
                                         │
[페이지]  쌓인 응원 메시지 → ❰워드맵❱ 으로 시각화   ← 받는 사람 감정보상 + 사회적증거 = "살아있는 콘텐츠"
            └▶ 예뻐진 워드맵을 주인공이 인스타에 재공유 ──▶ 다른 친구 유입 ──▶ 응원 추가 (확산 고리)
                                         │
[주인공]  클로버 누적 ──모이면(일정금액↑) 환전──▶ 현금   ◀── 여기서 take-rate = 메인 매출
```

핵심 설계 결정(대화 반영):
- **받는 사람 부담 최소** — 목표·일정·왜만. 살아 움직이는 콘텐츠는 *친구 응원(워드맵)이* 채운다(공급측 기록 숙제로 공급 마르는 것 방지).
- **조용히 = 비동기·무부담**(익명 강제 아님). 받는 사람은 *누가 응원했는지 본다*. 워드맵·"N명이 응원" 사회적증거는 보이되 **금액·과시는 가린다**.
- **응원=콘텐츠**: 워드맵 재공유가 다음 친구를 끌어오는 바이럴 엔진.
- **결제는 1일차 코어**(무결제 MVP 아님). 클로버·결제·적립·환전이 첫날부터 동작.
- ⛔ **시끄러운 뱃지·과시형 랭킹·금액 자랑·강제 호혜·감사답장 의무 금지.**

## 4. MVP 기능요구 (+ One Thing 연결)

> 기능 명세 수준만. 화면/플로우는 design 단계.

| # | 기능 | 요구사항(what) | One Thing 연결 |
|---|---|---|---|
| F1 | **목표 선언(액자)** | 주인공이 목표("○○ 해낼게")·일정·왜(이유) 작성. 진행 업데이트는 *선택*(가벼운 한 줄/사진, 강제 아님) | 주인공 목소리 = 선언. 응원의 트리거 |
| F2 | **조용한 응원 결제(하트/클로버)** | 친구가 1~2탭 간편결제, **로그인 최소**, 원하면 한 줄 응원(비동기), 은은한 도착 알림. 금액 비노출 | 친구의 "조용히 돈으로" 그 자체 |
| F3 | **응원 워드맵** | 쌓인 응원 메시지를 워드맵/구름으로 시각화, **재공유용 이미지 출력**, "N명이 응원" 집계(금액 X) | 받는 사람 보상 + 사회적증거 + 바이럴 콘텐츠 |
| F4 | **"해내면 쏜다" 마일스톤 pledge** | 친구가 달성 조건부 도네 예약("합격 시 3만원"), 달성 시 집행, 미달 시 환원/소멸 | 달성을 *걸고* 응원 — 도네를 목표 서사에 묶음(BM 보조 1순위) |
| F5 | **적립 & 환전(cash-out)** | 클로버 적립 → **모이면(최소환전액↑) 환전**, take-rate 수취, 월정산·3.3% 원천징수·KYC | 메인 BM. "모이면 내 손에" = 버티는 동기 |
| F6 | **linktree식 공유 링크** | 인스타 바이오/게시물에 박는 프로필 링크 → 친구 유입 → 로그인 없이도 조용히 결제 진입 | GTM 자가확산 엔진. 응원 루프의 입구 |

> ⚠️ F2·F5의 **결제·적립·환전 자금흐름 설계는 regulatory(risks #1)가 결정**한다. 베이스라인 = 외부 PG 경유. **적립형(잔액 보유)이라 전금법 무거운 등급** — 결제 빌드 전 변호사 자문(단, 게이트 순서는 §10 = *시장검증 먼저*).

**MVP 비포함(후행)**: 팔로우/팔로잉 **커뮤니티**(코어 밖, 회장 "핵심만 뿌린다"), 기업 스폰서(공급풀 후), 시끄러운 랭킹/리더보드, 라이브 후원(함정1).

## 6. BM (요약 — 정본: bm.md)

- **메인**: 환전 수수료 take-rate(목표 순플랫폼 10~15%, 천장=투네이션 all-in 6.3%·별풍선 20%+ 사이). 정확한 율은 시장 보고 확정(Open-Q3 = defer).
- **보조1순위**: "해내면 쏜다" 마일스톤 pledge(객단가↑·동기 루프).
- **보조 후행**: 기업 스폰서(공급풀 후).
- **단위경제 핵심**: 소액 결제 + PG 정액수수료 → 건당 순익 얇음 → **자가확산(CAC≈0)이 생존 전제**. 12M 매출: Bear ~600만 / Base ~5,000만 / Bull ~4억.

## 7. GTM

1차 = **인스타 바이오 linktree**. 공스타(공부 인스타) 운영계정/개인 프로필에 "여기 기록하고 친구한테 조용히 응원받으세요" 링크 → 친구 유입 → 조용히 결제 → 워드맵 재공유로 확산. openclaw 마케팅 테넌트 신규(ZERO-ONE과 분리).

> 🔴 **콜드스타트 밑돌(검증 대상)**: 친구가 *인스타에서 링크 타고 우리 앱까지 넘어와 하트를 누르는* **그 한 단계 전환율**이 양면시장 생사. 이걸 풀빌드 전에 싸게 실측한다(§10 컨시어지).

## 8. 리스크 (요약 — 정본: risks.md)

- 🔴 **#1 전자금융거래법(존립 조건)**: 클로버=선불전자지급수단 발행+환전, **적립형(잔액 보유)**이라 전금업 등록/선불충전금 100% 별도관리(2026-12-17 강화) 등급 가능. 베이스라인=외부 PG 경유. 결제 빌드 전 변호사 자문(순서는 §10).
- 🔴 **콜드스타트 전환**(GTM §7): 인스타→앱 클릭→하트 한 단계가 안 돌면 양면 안 큼. 최우선 검증.
- 🟠 kill-criteria 3: (1)리텐션 W4<~20% (2)결제 전환(1회경험·반복후원율) 미달 (3)단위경제/규제(LTV<CAC·전금법 불가).
- 🟡 ZERO-ONE 자기잠식, 미성년 결제·환전(Q4), 어뷰징·셀프후원 자금세탁.
