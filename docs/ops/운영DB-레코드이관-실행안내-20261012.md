## 회장이 할 한 줄

현재 운영 프로젝트(`ossvejipdivgxzcqszbw`)의 **데이터베이스 비밀번호**만 키체인에 넣으면 된다.
**값을 채팅에 붙여넣지 마라.** 아래 명령은 입력을 가린 채 받는다.

```bash
security add-generic-password -U -s supabase-db-password -a haenael-ge-new -w
```

비밀번호는 대시보드 `Project Settings > Database > Database password` 에 있다.
기억나지 않으면 같은 화면에서 재설정한다. 운영 웹앱은 이 비밀번호를 쓰지 않으므로
재설정해도 서비스에 영향이 없다(앱은 API 키로 붙는다).

넣은 뒤 이것만 실행하면 끝난다.

```bash
bash scripts/ops/apply-migration.sh
```

14단계를 하나씩 넣고 매 단계 행 수를 찍는다. 마지막에 기대값과 대조한다.

## 왜 세션이 끝까지 못 했나

현재 운영 DB 의 비밀번호가 이 맥 어디에도 없다. 키체인에 있는
`supabase-db-password / haenael-ge` 는 **이전 프로젝트** 것이고 그것으로는 이전 DB 만 열린다.
`Supabase CLI` 토큰은 또 다른 계정(vibe-doctor·haejo-danta) 것이라 두 프로젝트가 안 보인다.

대시보드 화면에서 키를 긁어내는 것, 토큰으로 질의 API 를 호출하는 것,
브라우저 자동화로 운영 DB 에 쓰는 것은 전부 자동 모드 분류기가 막는다.
**우회하지 않았다.** 그 차단은 운영 데이터와 자격증명을 보호하는 것이고 옳다.
