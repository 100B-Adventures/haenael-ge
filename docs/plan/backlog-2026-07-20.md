## 프로필(F2) — 담당 의견
받는사람 프로필(사진·한줄 소개)은 **있는 게 맞다**: 친구가 "누구를 응원하는지" 인지해야 응원 정서·전환↑. 지금 물음표(?)는 미완성 인상. 단 "조용히" 컨셉과 균형 — 과한 자기PR 아니라 **카카오 로그인 시 받아오는 프로필 이미지+닉네임**을 기본 활용(scope에 profile_image 있음)하고, 한줄 소개는 선택. 즉 별도 업로드 UI 없이 카카오 연동만으로 물음표 해결 가능(MVP). 소개/편집은 마이페이지(M3)에 묶기.

## 우선순위 제안
1. **F3 신고 버그** (실버그, 즉시 수정)
2. **M4 "나만 보임" 라벨 + M2 링크 아이콘** (작은 디자인, 빠름)
3. **F2 프로필(카카오 이미지 연동) + M5 워드맵 디자인** (디자인 개선)
4. **M3 마이페이지 + F2 소개 편집** (신규 기획→디자인→구현)
5. **F1 결제/토스** (회장 트랙, 외부 선결)
