## 1. 계정 정본 표

### 1-1. 핸들 [확정 — 2026-07-30]

> **확정값 = `@haenaelge`** (인스타그램 실개설·적용 완료, 관찰됨). 개설 당시 오타 핸들 `haenalge.official`로 만들어졌던 것을 회장 지시("도메인 따라가")로 계정 센터에서 `haenaelge`로 교정했다. 서비스 도메인 `haenael-ge.vercel.app`·가입 이메일 `haenaelge.official@gmail.com`과 철자 일치. 스레드는 인스타와 username 공유로 자동 동일, 유튜브는 개설 시 같은 값 수동 입력.

**표시명 "해낼게 ⏐ 목표 선언 응원" 근거**: 인스타 검색에서 가장 가중치 높은 필드 = name field이고, "브랜드 ⏐ 핵심 키워드" 형식(예: "Alice ⏐ Yoga Teacher")이 2026 인스타 SEO 표준 권고다 (근거: seosherpa.com/instagram-seo, later.com/blog/instagram-seo). 키워드는 도경이 검색할 말 = "목표"·"선언"·"응원". "공부"를 넣지 않는 이유 = ZERO-ONE 분리 원칙(정본 §1) + 다이어트·이직 등 TAM 확장(서연 페르소나) 여지. 토스(`토스`)·당근(`당신 근처의 당근🥕`)은 이미 인지도가 있어 키워드 없이 가는 케이스라 신생 브랜드엔 부적합 — 키워드형 채택.

### 1-3. 프로필 링크 구조 — 직접 도메인 [stable-제안], linktree류 배제

**기본값 = 서비스 도메인 직접 연결.** 근거 3개:

1. **자기부정 방지**: 해낼게 제품 자체가 "링크-인-바이오 프로필" 아키타입이다 (DESIGN.md §0). 링크인바이오 서비스가 남의 링크인바이오(linktr.ee)를 쓰는 건 카테고리 자기부정.
2. **전환 홉 제거**: 바이오 링크→linktree→랜딩은 클릭 1회 추가 = 퍼널 손실. 인스타는 현재 바이오에 링크 5개까지 직접 등록 가능해 linktree의 존재 이유가 약함 (근거: later.com/blog/instagram-seo 계열 2026 가이드).
3. **신뢰**: 돈이 오가는 서비스가 `linktr.ee/...` 도메인이면 피싱 인상 (DESIGN.md Trustworthy 원칙).

도메인 확정 전 임시값 = 사전등록 랜딩 URL(P0 산출물). **⛔ 도메인 미확정 — 문서 끝 회수 필요 참조.**

## 2. 바이오 카피 (플랫폼별 완성본)

### 돈 언어 적용 판정 (셀프심문 결과 명시)

- 정본 §2-2의 "주인공 면 돈 언어 0"의 적용 대상 = **선언 페이지·공유 카드·프로필 임베드** (유저 개인의 면). 브랜드 계정 바이오는 여기 속하지 않는 **브랜드 공개면**이다 — D-005(유튜브 배너=브랜드 공개면이므로 슬로건 유지)와 같은 논리.
- 단, **면의 성격 ≠ 청중의 성격**. 인스타 바이오의 1차 열람자 = 공스타 주인공 후보(도경)이고, 도경의 이탈 트리거 = "쟤 돈 걷네" 프레임(정본 §2-3). → **인스타 바이오는 '허용되지만 자제'** — 돈 단어 0, 슬로건 없음, 선언·응원 프레임만.
- 스레드 바이오의 1차 열람자 = 의심 해소 단계의 응원자·관찰자 → 슬로건 정면 배치 (정본 §4 "슬로건 도발 카피 주 무대").
- 유튜브 채널 설명 = 배너에 이미 슬로건이 있으므로(D-005) 설명문도 일관되게 포함.

### 2-1. 인스타그램 바이오 [stable-제안] (150자 제한, 실측 58자)

```
말하면 시작된다. 해낼게 🍀
친구의 목표 선언에, 조용히 마음을 두고 가는 곳
선언은 프로필 링크에서 👇
```

| 줄 | 심리 트리거 | 설계 |
|---|---|---|
| 1 | 커밋먼트·일관성 (치알디니) — 선언 자체가 이행 압력을 만든다 | P2 대표 카피 그대로. 선언 층 단호체 |
| 2 | 무부담 호혜 — "두고 가는"은 답례 의무(민지의 페인)를 제거하는 어휘표 정본 단어 | 대화 층. 돈 단어 0 |
| 3 | 행동 유도 — 링크 클릭 단일 CTA | "가입하세요" 아닌 "선언은"(요청 아닌 행위 명명) |

### 2-2. 스레드 바이오 [stable-제안] (61자)

```
응원은 돈으로 하는 겁니다.
휘발되는 화이팅 대신, 조용히 두고 가는 마음 🍀
해낼게 만드는 중 — 제작기 연재
```

| 줄 | 심리 트리거 |
|---|---|
| 1 | 위반 기대(도발) — 스크롤 정지. 슬로건 노출면 정본 규칙 내 |
| 2 | 손실 회피 — "휘발"이 기존 화이팅의 무가치를 명명 (P1) |
| 3 | 프로세스 이코노미 — 만드는 과정 공개 = 신뢰 선납 (S1 연결) |

### 2-3. 유튜브 채널 설명 [stable-제안]

```
응원은 돈으로 하는 겁니다.

친구가 "나 ○○ 해낼게"라고 선언하면, 친구들이 조용히 클로버 🍀 로 밀어주고 — 해내면 그 마음이 친구 손에 들어가는 곳, 해낼게입니다.

하트 마흔 개는 3초 뒤에 사라지지만, 조용히 두고 간 클로버는 해내는 날까지 남아 있어요.

이 채널에는 두 가지가 올라옵니다.
① 해낼게 선언 로그 — 목표를 선언한 사람들의 진짜 서사
② 만드는 중 — "응원은 돈으로 하는 겁니다"를 만드는 과정 전부

선언은 아래 링크에서 시작할 수 있어요.
```

첫 문단 = 슬로건+압축 한 문장(정본 §1). 이후 대화 층("~어요")으로 전환 — 톤 2층 구조 그대로.

## 3. 해시태그 시스템 — 3층 구조

### 2026 효용 전제 (실조사)

해시태그는 더 이상 도달 엔진이 아니라 **알고리즘 분류 신호**다. Adam Mosseri(인스타 CEO) 공식 확인: "해시태그는 도달을 늘리지 않는다 — 콘텐츠를 분류한다." 권장 = 게시물당 **3~5개**, 관련성 높은 니치 태그(게시물 5만~50만 규모)가 메가 태그 대비 도달 대비 참여 3배 (근거: later.com/blog/ultimate-guide-to-using-instagram-hashtags, funnl.ai/do-instagram-hashtags-work-in-2026, manychat.com/blog/instagram-hashtag-strategy). 캡션 키워드가 해시태그보다 도달 기여 큼 → **캡션 첫 문장에 "선언·응원·해낼게" 자연 삽입이 태그보다 우선.**

### 3층 구조

| 층 | 태그 | 역할 |
|---|---|---|
| L1 브랜드 | `#해낼게선언` (1차) · `#해낼게` (보조) · `#클로버응원` [실험] | 브랜드 검색 허브. **`#해낼게선언`이 1차인 이유**: "#해낼게"는 일상 동사라 일반 게시물로 이미 오염 — 단 그 오염이 곧 ambient 노출이라 보조로 유지 (unsourced — 개설 후 태그 탭 실확인) |
| L2 목표군 (니치) | `#편입준비생` `#자격증공부` `#이직준비` `#재수생` `#다이어트인증` `#영어공부인증` | 관심사 기반 사회적 증거(D-003 ②)와 직결 — "편입 준비, 지금 N명이 해낼게 중" 콘텐츠가 이 태그로 꽂힘 |
| L3 도달 (대형) | `#공스타그램`(720만+, 2022 국내 최다 팔로우 태그 — 근거: zdnet.co.kr/view/?no=20221213103042) `#공부인증` `#스터디플래너` `#갓생` | 분류 신호용 1개만. 도달 기대 금지 |

### 게시물당 조합 규칙 [stable-제안]

> **L1 1개 + L2 1~2개 + L3 1개 = 총 3~4개.** 5개 초과 금지.
> 선언 카드형 게시물 = `#해낼게선언` 필수. 응원자 각도 게시물 = L2 생략 가능.
> `#스터디모집` `#같이공부` 계열 = **금지** (ZERO-ONE 분리, 정본 §1).

[실험] 판정 게이트: 8주 후 `#해낼게선언` 태그 탭에 유저 자발 게시물 10건 미만이면 L1 태그를 선언 카드 템플릿에 박아 강제 노출로 전환.

## 4. 인스타 첫 9게시물 그리드 계획 — v3 핀 재설계 (2026-07-21b, 회장 지적 반영)

> **회장 지적(2026-07-21)**: "핀은 상단에 3개만 걸 수 있어, 다시 생각해봐." → 실조사 결과 지적이 정확함을 확인: 인스타 핀은 **핀된 3개를 원래 위치와 무관하게 항상 그리드 최상단 1행(위치 1·2·3)으로 강제 이동**시킨다(최근 핀=최좌측, techcrunch.com/2022/06/07/instagram-pin-posts-to-your-profile). 구 v2 계획의 "PIN=1·5·9(좌상·정중앙·우하 대각선)"는 **핀을 거는 순간 셋 다 1행에 나란히 재배치**되어 대각선 구도 자체가 물리적으로 성립 불가능 — 실행 불가능한 설계였음을 인정하고 전면 재설계.
> **콜드 방문자 실제 체험(신규 확인)**: 프로필 방문자는 평균 **2~3초** 안에 팔로우 여부를 결정하고, 그 창에 보이는 건 정확히 프로필사진+바이오+**그리드 최상단 1행(=핀 3개)**뿐(thisisco.com.au/podcast/3-must-have-pinned-posts). 즉 9칸 중 "무조건 보장되는 노출"은 핀 3개뿐 — 나머지 6개는 스크롤해야 보이는 2차 자산. 그리드 설계는 이 전제로 재정렬한다.
> 비주얼 공통(변경 없음): DESIGN.md 토큰 — 웜 페이퍼 `#FBFAF7` 배경, 클로버 그린 `#1B8A4F` 채움만, Pretendard 단일 폰트, gradient 금지.

### 4-1. 새 PIN 3칸 = 01(매니페스토) · 02(캐러셀 커버) · 08(사용법 3스텝)

**선정 프레임 = Introduction → Connection → Action**(2026 브랜드 계정 핀 표준 프레임, minter.io/blog/6-of-the-greatest-posts-to-pin-on-instagram). 핀은 물리적으로 1행 3칸에 나란히 놓이므로, "정중앙 앵커"·"클로징" 같은 위치 의존 연출은 폐기하고 **연속된 3장이 하나의 문장처럼 읽히는가**를 기준으로 재선정했다.

| 순위(좌→우) | 칸 | 역할 | 왜 이 셋인가 |
|---|---|---|---|
| 1 | feed-01 매니페스토 "말하면 시작된다." | Introduction — 후킹, 브랜드가 뭔지 궁금하게 | 3초 창의 첫 인상. 슬로건급 단호체 한 문장으로 스크롤을 멈춘다 |
| 2 | feed-02 "해낼게가 뭐냐면" 캐러셀 커버 | Connection — 개념 설명 | "친구가 목표를 선언하면, 우리는 조용히 밀어줍니다"로 후킹 다음 궁금증(뭘 하는 곳인데?)에 즉답. 캐러셀형이라 관심 있는 방문자는 스와이프까지 유도(체류시간↑) |
| 3 | feed-08 사용법 3스텝 | Action — 실행 방법 | "①선언한다 ②링크를 프로필에 둔다 ③조용히 응원이 쌓인다" — 이해 다음 단계인 "그래서 나는 뭘 하면 되나"에 즉답. 마찰 제거로 이탈 전 마지막 설득 |

**기각한 대안 (셀프심문 — 사회적 증거를 핀에 넣는 안)**: feed-03/06 선언 카드(298명·156명 예시)를 핀 후보로 검토했으나 기각. 이유: ①이 수치는 D-009가 승인한 **런치 한정 가공 예시**로, 실 유저 선언이 쌓이면 순차 교체될 임시 콘텐츠 — 가장 눈에 띄는 영구 노출 슬롯(핀)에 임시 가짜 수치를 고정하면 나중에 실사례로 바꿀 때 재핀 작업이 추가로 필요하고, 그 사이 "가장 잘 보이는 자리"에 가짜 수치가 가장 오래 노출되는 리스크가 큼. ②Intro-Connection-Action 3장만으로 이미 "뭐 하는 곳·어떻게 쓰는지"가 완결되어, 증거는 스크롤 유도(2행)로 넘겨도 후킹 손실이 크지 않다고 판단. (레드팀 반론과 방어는 하단 §4-4 참조.)

**재배열 논리**: 1행(핀, 보장 노출) = 이해(Intro-Connection-Action). 2행(스크롤 시) = "진짜 쓰는 사람이 있다"(사회적 증거 2장) → "그게 뭔 뜻이냐면"(어휘 앵커) — 핀에서 이미 개념을 이해한 방문자가 다음으로 궁금해할 "증거"에 바로 응답. 3행 = 정서 후킹 2종으로 공감 심화 → 마지막 칸(9)에서 "우리도 선언부터 한다"는 브랜드 자기 선언으로 닫힘(자기적용 원리, 기존 v2 설계 의도 유지 — 위치만 우하 고정에서 자연 클로징 자리로 이동).

① "목표는 머릿속에 있을 때가 아니라, 입 밖에 나올 때 시작됩니다." ② "친구가 '해낼게'라고 하면, 우리는 조용히 밀어줍니다." ③ "새벽 6시 도서관 오픈런 8개월째..." **돈 언어 0** ④ "화이팅은 따뜻하지만, 3초 뒤에 사라집니다." ⑤ "클로버 🍀 = 친구가 조용히 두고 간 마음..." ⑥ "공부만 선언하는 곳이 아닙니다..." **돈 언어 0** ⑦ "'헐 왜 이런 걸ㅠㅠ' 그 어색함, 우리가 없앴습니다." ⑧ "시작은 선언 한 줄이면 됩니다." ⑨ "우리도 선언부터 합니다..."

### 4-3. 운영 실행 가이드 (회장용)

핀은 게시물을 다 올린 뒤 마지막에 지정한다. 순서를 지켜야 좌→우가 01·02·08이 된다("나중에 핀한 게 최좌측" 규칙 이용):

1. **업로드(오래된 것→최신 순)**: 09 → 07 → 04 → 05 → 06 → 03 → 08 → 02 → 01
2. **핀 지정(전부 업로드 후, 반드시 이 순서로)**: 08번 게시물 핀 → 02번 게시물 핀 → 01번 게시물 핀(마지막). 결과: 그리드 좌→우 = 01·02·08.
3. 핀 이후 위치 4~9는 비핀 게시물 6개가 업로드 최신순으로 자동 정렬 — 위 §4-2 표가 그 결과다(추가 조작 불요).

**제작 완료물**: `docs/brand-assets/feed/feed-01-manifesto.png` ~ `feed-09-start.png`(각 1080×1350, 카피·비주얼 v2와 동일) + 재구성 프리뷰 `feed-preview.png`(실제 인스타 렌더링 결과를 반영한 그리드). footer 워드마크 텍스트는 신규 PIN(1·2·8)에만 남기고 05·09는 아이콘만으로 되돌림(R10 "매 게시물 워터마크 반복 금지" 원칙 유지, design-benchmark-bank.md R10 보강 참조). 소스: `docs/brand-assets/feed/_src/feed-template.html`(개별 카드) + `_src/feed-preview-template.html`(그리드 프리뷰, 신규 — design-html, 헤드리스 gstack browse 렌더).

### 4-4. 셀프심문 + 레드팀 1회

**셀프심문**: "핀 3개만 보고 콜드 방문자가 이탈하지 않고 '들어가볼까' 되나?" → 01(후킹)로 멈추고, 02(캐러셀, "친구가 선언하면 우리가 민다")로 "아 이런 서비스구나" 이해하고, 08(3스텝)로 "그럼 나도 해볼까"까지 논리가 끊기지 않는다. 다만 02가 캐러셀형이라 **정지 이미지만으로는 "5장 넘겨보기"가 실행되지 않을 수 있다**는 갭은 남음 — 캐러셀 스와이프 없이도 헤드라인 한 줄("친구가 목표를 선언하면, 우리는 조용히 밀어줍니다")만으로 이해가 완결되게 이미 설계되어 있어(스와이프는 보너스, 필수 아님) 갭은 낮게 평가.

**레드팀(회의적 신규 방문자 관점)**: "핀 3개 중 어디에도 '진짜 쓰는 사람'이 없다. 개념 설명뿐인 브랜드는 신뢰가 안 간다"는 공격이 가능. 방어: ①2행(위치 4·5)에 사회적 증거가 스크롤 1회 거리에 있고, 인스타 그리드는 관심 있는 방문자가 자연히 아래로 스크롤하는 UX라 "완전히 안 보인다"는 아니다. ②콜드스타트 단계의 사회적 증거는 D-009 가공 예시라 애초에 "진짜"가 아니므로, 이걸 가장 신뢰가 걸린 슬롯(핀)에 앞세우는 게 오히려 리스크(§4-1 기각 사유와 동일 논리 — 레드팀이 이 갭을 지적해도, 가짜 증거를 더 눈에 띄게 만드는 것보다 낫다는 판단 유지). ③실 유저 선언이 쌓이면(수 주 내 예상) 사회적 증거 칸을 진짜 사례로 교체하고, 그 시점에 핀 3번(08)을 실 사례로 교체하는 재검토를 권고(§4-5로 이관).

### 4-5. 다음 재검토 트리거 [실험]

실 유저 선언이 5건 이상 누적되면: ①2행(위치 4·5)의 가공 예시를 실사례로 교체 ②핀 3번(현재 08 사용법)을 "실사례 1건"으로 교체할지 재논의 — 이때는 사회적 증거가 가짜가 아니므로 §4-1의 기각 사유가 소멸한다.

| 5 | "선언 페이지를 열었습니다. 아직 결제는 없습니다. 선언만 됩니다." | 무결제 선언 페이지(P1 플랜) 안내 — "먼저 선언이 쌓여야 응원이 흐릅니다" | 링크 클릭 (사전등록/선언) |

## 7. 회장 5분 개설 가이드

> ⚠️ 콘솔 화면은 수시로 바뀝니다. **아래 경로와 실제 화면이 다르면 추측 진행하지 말고 캡처 후 문의해 주세요.**
> 준비물: 브랜드용 이메일 1개, `docs/brand-assets/profile-icon.png`, `youtube-banner.png`, 이 문서(복붙용).

### ① 인스타그램 (약 2분)

1. https://www.instagram.com/accounts/emailsignup/ 접속 (또는 앱에서 신규 가입)
2. 이메일 가입 → 사용자 이름에 `haenaelge` 입력 → **사용 불가 시 §1-1 폴백 순서대로** (`haenaelge_official` → `haenaelge_app` → `haenael.ge`)
3. 가입 후: 프로필 편집 → 사진 = `profile-icon.png` / 이름 = `해낼게 ⏐ 목표 선언 응원` / 소개 = §2-1 복붙 / 링크 = 랜딩 URL
4. 프로페셔널 전환: 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → 카테고리 검색에서 **제품/서비스** 선택 → 비즈니스
5. 확인할 것: 프로필에서 이름·소개·링크가 이 문서와 글자까지 일치하는지, 카테고리 라벨이 프로필에 표시되는지

### ② 스레드 (약 1분)

1. https://www.threads.com 접속 → 방금 만든 인스타그램 계정으로 로그인
2. 프로필 가져오기 화면에서 인스타 프로필 기반 생성 → 생성 후 프로필 편집에서 **소개만 §2-2로 교체** (스레드는 소개·링크를 인스타와 별도로 둘 수 있음 — 사진·사용자 이름은 인스타와 공유)
3. 확인할 것: 스레드 소개에 슬로건 첫 줄이 들어갔는지, 인스타 소개가 안 바뀌었는지 (바뀌었으면 캡처 후 문의)

### ③ 유튜브 (약 2분)

1. https://www.youtube.com 접속 → 브랜드용 Google 계정으로 로그인 → 우상단 프로필 → "채널 만들기" → 이름 `해낼게`
2. https://studio.youtube.com → 왼쪽 메뉴 "맞춤설정" → **브랜딩 탭**: 사진 = `profile-icon.png`, 배너 이미지 = `youtube-banner.png`
3. **기본 정보 탭**: 핸들 = 인스타 확정 핸들과 동일하게 입력 / 설명 = §2-3 복붙 / 링크 1·2 추가
4. 확인할 것: 채널 페이지에서 배너 슬로건이 모바일 크롭에서도 잘리지 않는지 (잘리면 캡처 후 문의), 핸들 URL(youtube.com/@핸들)이 열리는지
