### 1-2. 태그 사전 (8개 고정 — 늘리기 전 회장 회수. 좁고 일관된 태그셋이 스케일한다)

수집물마다 ①태그 ②**verbatim 원문 인용**(요약 금지 — 요약은 조작이 스민다) ③소스·날짜를 남긴다. 판정 기준 = 즉시 대응 vs 주간 집계.

| 태그 | 정의 (신호 예) | 대응 | 반영처 |
|---|---|---|---|
| **[역화]** | 주인공 면 돈 언어 오염 반응 — "쟤 돈 걷네"·"구걸이냐"류, 선언자가 돈 걷는 사람으로 읽히는 모든 반응 | **즉시 — §3 트리거 ①** | 해당 면 전수 grep 재검([first-revenue-playbook §6-2](first-revenue-playbook.md)) + 회장 보고 |
| **[침식]** | 댓글·공유 캡션의 금액 언급("5천 원 두고 감") — 정본 §2-4 ⓓ 침식 감시 | **즉시** — 해당 카피·화면 검토 착수, 확산 전 회장 보고 | 카피뱅크 해당 ID 검토 |
| **[오해]** | 카테고리 오독 — 내기·사행성·기부·모금으로 읽는 반응 | 주간 (동일 오해 3건+ = FAQ·P4-05형 카피 증설 제안) | 카피뱅크 P4 · 랜딩 FAQ |
| **[기능요청]** | 제품 기능 요구("익명 옵션 줘요"·"환전 언제 돼요") | 주간 집계 — **구현·약속 금지**(제품 기능 = 회장 회수, [agent-runbook §④](../../3-operations/agent-runbook.md)) | 다이제스트 → 기획 회수 |
| **[감동사례]** | 유저 서사 원석 — 첫 응원·해낸 날·복귀·관계 변화 썰 | 주간 (단 [해낸날]·[역할전환]급은 발생 즉시 동의 DM 착수) | **[story-canon §3](../../1-team-brand/story-canon.md) 라우팅 표**로 이관 |
| **[이탈사유]** | 떠난/거절한 이유 실발화("부담스러워서 지웠어요"·DM 거절 사유) | 주간 | 다이제스트 상위 5선 후보 1순위 |
| **[밈발생]** | 선언 문장·포맷의 자발 변형 사용("나도 ○○ 해낼게" 비유도 사용, 템플릿 리믹스) | 주간 — §4 터짐 판정 입력. **부정 밈**(조롱 변형)이면 즉시 | §4 Loop3 증폭 판단 |
| **[광고티]** | 콘텐츠 신뢰 손상 반응 — "광고였네"·"바이럴이네"(S3 브랜드 연결 시점 등) | 주간 (2건+ = 연결 수위 한 단계 후퇴 — S3 게이트 승계) | 시리즈 브랜드 연결 규칙 |

- 기록처: 태그 로그는 주간 단위로 §5 다이제스트에 집계 — 낱건 로그는 운영 시트(수기)에. 볼륨이 월 수백 건을 넘으면 자동 분류 도입 검토(그 전엔 수동이 정확하다 — 벤치마크: 수동 태깅은 소볼륨에서만 유효 https://www.enterpret.com/guides/how-to-organize-customer-feedback-with-a-taxonomy).

## 2. 주간 다이제스트 규격 [stable — 주기는 회장 확정]

**주기 = 주 1회, 일요일 체크인에 통합**([agent-runbook §②](../../3-operations/agent-runbook.md) 일요일 루틴의 ①~⑤에 **⑥ 정성 다이제스트** 칸으로 추가 — 루틴 자체는 그쪽 정본). 회장 결정도 주 1회 이 다이제스트로 묶어 올린다 — 낱건 결정 요청 남발 금지(즉시 트리거 §3 제외).

**다이제스트 포맷 (회장 보고 블록 — 이대로 제출):**

```text
── 해낼게 주간 정성 다이제스트 W{n} ({날짜}) ──
정성 신호 상위 5선 (태그 | verbatim 인용 | 건수/소스 | 제안 액션 | 반영처)
1. [태그] "원문 그대로" | n건/스레드 | 액션 1줄 | 카피뱅크 P○ / 시리즈 S○ / 기획 회수
2~5. (동일 형식 — 5건 미만이면 있는 만큼만. 채우기용 승격 금지)
루프 계기판: Loop1 ○ / Loop2 ○ / Loop3 ○ (§4 신호 지표 실측값, 미측정은 사유)
터짐 판정: (2주 연속 조건 충족 루프/포맷 있으면 명시 + 증폭안, 없으면 "없음")
회장 결정 필요: (기능요청 집계·정책 판단 등 — 무엇을/하면/안 하면/추천)
```

- 상위 5선 선별 기준: **빈도 × 심각도**(역화·이탈 > 오해 > 요청) — 목소리 큰 1건이 아니라 반복되는 신호(벤치마크: 우선순위는 볼륨·세그먼트 기준, loudness 아님 — https://www.koji.so/docs/customer-feedback-categorization).
- 아카이브: 다이제스트 요약 1줄을 §5 로그에 append + 진행 1줄은 [agent-runbook §⑤-3](../../3-operations/agent-runbook.md) 관례대로.

## 3. 즉시 회수 트리거 — 다이제스트를 기다리지 않는다 [stable-제안]

아래는 발견 즉시 `⛔ 회수 필요` 형식으로 회장 보고. **하위모델의 홀딩 액션은 "추가 발행 중지"까지만** — 삭제·공개 사과·반박 대응은 회장 결정 사안(임의 삭제가 폭로 프레임을 키운다).

1. **[역화] 실발화 1건이라도** — "쟤 돈 걷네"류가 실유저 입에서 나오는 순간(공유 루프 사망 신호 — 빈도 기다릴 사안 아님). 홀딩: 해당 면 관련 발행 중지 + grep 재검.
2. **언론·인플루언서 접촉** — 취재 문의, 대형 계정의 인용/비평(긍·부정 무관). 임의 인터뷰·자료 제공 금지.
3. **법적 신고류** — 개인정보·초상권 침해 주장, 미성년 관련, 사행성 신고·심의 언급, 결제 분쟁. 법무 해석 = 회수([agent-runbook §④](../../3-operations/agent-runbook.md)).
4. **계정 제재 신호** — 밴 경고·노출 제한 통지 (DM 감속 브레이크는 기존 재량 의무 그대로 — 이 항목은 '보고'가 추가되는 것).
5. **시드 콘텐츠 조작 프레임** — "이 계정 사연 지어낸 거 아니냐"류 공개 제기(S2 셀프심문의 최악 시나리오). 홀딩: 시드 신규 발행 중지, 재구성 고지 위치 확인.
6. **금액 역산 가능 노출 발견** — 화면·콘텐츠 어디서든(침식 임계선 = 에토스 사망선, 정본 §8).

## 4. 성장 루프 포트폴리오 — 3종 전부 깔고, 터지는 것을 키운다 [stable — 회장 원문]

> 회장 원문: "할 수 있는 건 다 해놓고 반응 터지는 거 유지하고 키우기."
> 각 루프를 ①**지금 콘텐츠 층에서 실행 가능한 부분**과 ②**제품 기능이 필요해 회장 회수인 부분**으로 분리한다([agent-runbook §④](../../3-operations/agent-runbook.md) "제품 기능 추가/변경 요구 = 회수" 준수 — 하위모델은 ①만 실행, ②는 제안·집계까지).

### Loop 1 — 응원자 → 선언자 전환

| 층 | 내용 |
|---|---|
| ① 콘텐츠 층 (지금 실행) | S3 관찰기 후반부 CTA를 전환 각도로("당신의 해낼게는 무엇인가요?" — 응원자 독자에게) · S2 EP8(역할 전환 서사) 트리거 발생 시 최우선 발행 · [역할전환] 실사례를 응원자 면 포스트로 재가공(양쪽 동의) |
| ② 제품 층 (**회수**) | 결제 완료 화면에 "나도 선언" 진입점 · 응원자 식별 기반 전환 추적(응원자→`goal_created` 연결) — 구현 여부·우선순위 = 회장/build |
| 측정 | 역할 전환 사례 수(P3 게이트 지표 — DB에서 응원 이력 보유자의 `goal_created` 교차, 현재 **수기 확인**) · 콘텐츠 프록시 = 전환 각도 포스트의 UTM 유입→선언 전환([kpi-runbook §2-2](kpi-runbook.md) 산식 준용) |
| 터짐 신호 | 전환 각도 포스트의 프로필 클릭·선언 전환이 일반 S3 대비 우위 2주 연속 |

### Loop 2 — 해낸 날 공유 카드

| 층 | 내용 |
|---|---|
| ① 콘텐츠 층 (지금 실행) | [해낸날] 태그 발생 즉시 S2 EP7 발동(동의+마스킹 회수 선결) · "해낸 날 카드" 카피·비주얼 규격 사전 제작([visual-guidelines](../../1-team-brand/visual-guidelines.md) 규격 내, **주인공 면 = 돈 언어 0** — "해냈다" 과거형 축, 금액·보상 언급 절대 금지) |
| ② 제품 층 (**회수**) | 달성 처리 시 자동 카드 생성·공유 플로우 · 카드 공유 이벤트 계측 세분화 | 
| 측정 | DB `share_event`(실재 테이블 — [architecture](../../../docs/architecture.md)) 중 달성 시점 공유 분리 집계 · GA4는 `wordmap_shared`만 실정의, 선언카드용 `goal_shared`는 **제안 상태**([kpi-runbook §3-2](kpi-runbook.md) 승계) — 이벤트 추가는 build 회수, 그 전까지 `(구현 미대조)` 병기 |
| 터짐 신호 | 달성 카드 1장당 유입·선언 전환이 일반 선언 카드 대비 우위 (첫 달성자 발생 전엔 측정 불가 — `미측정(달성 0건)` 기록) |

### Loop 3 — 선언 문장 밈 템플릿 3종 (전부 콘텐츠 층 — 지금 실행 가능)

기존 [stable] 카피 축의 참여형 변환이라 신규 발명 아님. **전부 주인공 면 규격 — 돈 언어 0, 검증 grep([first-revenue-playbook §6-2](first-revenue-playbook.md) ②) 통과 후 배포.** 발행 슬롯을 먹지 않는 형태(스토리 템플릿·고정글·인용 유도)로 깔아 캘린더 케이던스 비침범.

| 템플릿 | 형식 | 원 카피 축 | 배포·참여 방식 |
|---|---|---|---|
| **M1 "○○, 해낼게."** | 빈칸 선언 카드 — 목표만 채우는 타이포 템플릿(D-day 슬롯 포함) | P2-01·S2 컷1 [stable] | 공스타 스토리 템플릿 배포("이어서 채우기") + `#해낼게선언` 태그 유도(D-007 1차 태그) |
| **M2 "속으로 백 번, 선언 한 번."** | 대비형 2컷 — 속다짐 vs 선언 비포/애프터 | P2-02 | 스레드 인용 유도("당신이 속으로만 백 번 다짐한 것 하나?") + 공스타 캐러셀 변형 |
| **M3 "D-{n}, 오늘도 같은 문장으로 하루를 연다."** | 반복 의식형 — 매일 같은 선언 문장+날짜 스탬프 | P2-05 | 공스타 인증 문화(열품타·플래너)에 얹는 캡션 포맷 — 반복 사용이 곧 확산 |
| 측정 | `#해낼게선언` 사용 절대수(주간 수기 집계 — 플랫폼 검색 기준 명시) · 템플릿 리믹스·인용 수 · UTM(`utm_medium=bio`) 유입 기여 · [밈발생] 태그 건수 |
| 터짐 신호 | 특정 템플릿의 자발 사용(비유도)이 2주 연속 증가 + [밈발생] 태그 집중 |

### 터짐 판정 → 증폭 규칙 [실험 — 기본값, 4주 실측 후 재캘리브레이션]

- **판정**: 루프/포맷의 신호 지표가 **2주 연속** 자기 채널 직전 4주 중앙값 대비 **≥2배**, 또는 단일 게시물이 채널 평균 대비 10배+ 이상치 → "터짐 후보"로 다이제스트에 기재. **1회 이상치만으로 증폭 금지**(우연 대박에 케이던스를 태우지 않는다).
- **증폭 (하위모델 재량 내)**: 해당 포맷 증편(캘린더 §1 재량 한도 내) · 변형 생산(같은 축 3변형) · 고정글/하이라이트 상위 배치 · 해당 소재의 시리즈 크로스오버.
- **증폭 (회수)**: 광고비 투입 · 신규 채널 개설 · 제품 기능화 · 인플루언서 협찬 — 전부 [agent-runbook §④](../../3-operations/agent-runbook.md) 우측 열.
- **유지 규칙**: 안 터진 루프도 **접지 않는다** — 회장 원문 "다 해놓고 유지". 3루프 동시 유지가 케이던스를 초과하면 우선순위 = 터진 것 > [감동사례] 연동 루프 > 나머지 최소선(격주 점검). 루프 폐기 판단 = 회장.

## 셀프심문 (CoVe + 레드팀)

**Q1 (지정). "이 문서를 GPT가 읽고 8주 돌렸을 때 회장 의도와 가장 어긋날 지점은?"** — **답: '터짐'을 1회 대박 게시물로 오독해 케이던스를 깨고 올인하거나, 반대로 [기능요청] 집계를 스스로 '구현하겠다'로 넘는 것.** 방어: 터짐 판정에 2주 연속 조건을 박고 1회 이상치 증폭을 명문 금지 + 증폭 액션을 재량/회수 두 열로 물리 분리 + Loop 1·2의 제품 층에 "회수" 볼드 반복. 차유력 = verbatim 인용 의무를 요약으로 대체해 신호를 각색하는 것 — §1-2에 "요약은 조작이 스민다"로 이유까지 박아 차단.
**Q2. "태그 8개가 부족해서 [기타]가 비대해지면?"** — 그때가 태그 개정 시점이지 임의 증설 시점이 아니다 — 증설 = 회장 회수로 못박음(태그 인플레는 집계 무력화). 미분류분은 다이제스트에 "미분류 n건 + 대표 예"로 노출해 개정 신호로 쓴다.
**Q3 (레드팀 — 회의적 운영자). "정성 태깅은 노가다인데 GA4 숫자로 갈음하면 안 되나?"** — 안 된다. [역화]·[침식]은 숫자에 안 잡히고(공유율이 떨어진 '뒤'에야 정량에 뜸), 이 서비스의 사망 시나리오가 전부 정성 신호 선행형이다(역화→공유 사망). 정성이 조기경보, 정량이 판정 — 역할이 다르다.
**Q4. "밈 템플릿이 금지선 위반?"** — M1~M3 텍스트에 금지어·돈 언어 0 확인(육안 + 원 카피가 전부 기검증 [stable]/카피뱅크 ID). M2 "속다짐" 대비는 P2-03(기분이다)의 도발 수위가 아니라 P2-02의 비교 수위 — 주인공 면 안전. 배포 전 개별 산출물 grep은 §4 규정대로 별도 실행.
