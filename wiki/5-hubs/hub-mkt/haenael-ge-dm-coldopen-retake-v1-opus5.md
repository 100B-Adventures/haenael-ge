## 0. 전제 교체 — 문안이 서야 할 정확한 지점

| | 2026-07-21 프리테스트 | **2026-08-01 현재 (이 문서)** |
|---|---|---|
| 결제 | 테스트 결제만 | **실결제 작동** (라이브 결제 모달·승인 확인, 회장 2026-08-01) |
| 정산 | 미가동 | 수동 (계좌 입력 방식) |
| 실 선언자 | 0명 | **여전히 0명** |
| 정직한 프레임 | "아직 공사 중" | **"만들 건 다 됐는데, 아직 아무도 안 왔다"** |

**핵심 판단**: "준비 중"은 이제 거짓이고("문 열기 전"은 사실이 아니다 = marketing.md §4 위반), "많은 분들이 쓰고 있다"도 거짓이다(선언자 0명). 둘 다 아닌 참인 문장은 딱 하나다.

> **"만들 건 다 만들었는데, 아직 아무도 선언을 안 했어요. 그래서 지금 오시면 말 그대로 첫 번째예요."**

이 문장이 이번 리테이크의 축이다. 프리테스트가 미완성을 사과로 쓴 자리에, **비어 있음을 자리로** 바꿔 넣는다. 심리 장치 = **선점 정체성 + 역희소성**(밀어내지 않고 비어 있음을 드러내 오히려 자격을 주는 형태). 부작용 방어는 §4 Q2.

## 1. `ss7coco` 발송용 완성본 ⭐ (복붙 즉시 발송)

관찰 근거: bio "⚡️2027년 기술사 합격 / 🤷‍♀️30중반 워킹맘", 게시물 26개, 최근 = 한전 계통·차단방식·인버터 회로 손글씨 필기노트 + "7월 8주차 아침 공부로그" "7월 4째주(7.20~26) 타임스탬프".

```
한전 계통이랑 인버터 회로 필기, 손으로 정리해서 올리신 거 보고 왔어요. 7월 4째주 타임스탬프까지요.

일하면서 아침에 그걸 하고 계신 거잖아요. 누구 보라고 올리는 기록 같지가 않아서, 그래서 더 오래 봤어요.

저희는 '해낼게'라는 곳을 만들었어요. "나 2027년 기술사 해낼게"처럼 한 줄로 선언하면 페이지가 하나 생기고, 그 링크를 아는 사람들이 볼 수 있게 두면 댓글 "화이팅" 한 줄 대신 조용히 마음을 두고 갈 수 있는 곳이에요. 누가 얼마를 뒀는지는 아무에게도 보이지 않고, 해내는 날 그건 전부 선언한 사람 것이 돼요.

정직하게 말씀드리면, 만들 건 다 만들었는데 아직 아무도 선언을 안 했어요. 그래서 지금 오시면 말 그대로 첫 번째예요.

어떤 곳인지 먼저 보실 수 있게 페이지 하나만 보내드려도 될까요? 보고 아니다 싶으면 그냥 지나치셔도 돼요.
```

### 1-1. 왜 이 문장인지 (줄별 근거)

| 줄 | 장치 | 왜 |
|---|---|---|
| "한전 계통이랑 인버터 회로 필기… 7월 4째주 타임스탬프까지요" | 검증 가능한 구체 신호 | 2026 콜드 아웃리치 실조사 결론 = "확인 가능한 구체 신호"만이 스팸과 구조적으로 구별된다(saleshandy·prospeo). 회로명 2개 + 날짜 = 봇이 못 쓰는 문장 |
| "일하면서 아침에 그걸 하고 계신 거잖아요" | 인정(호감) | bio에 본인이 밝힌 사실만 사용. 육아·가정 상황은 **추측 금지**라 한 글자도 안 넣었다 |
| "누구 보라고 올리는 기록 같지가 않아서" | 리버설 | 팔로워 2인이라는 사실을 **언급하지 않고** 그 상태를 존중으로 전환. "영향력 있으셔서" 류 거짓 아부(즉시 실격)의 정반대. 관객 없이도 26개를 쌓은 사람에게 가장 정확한 인정 |
| "아는 사람들이 볼 수 있게 두면" | 반론 선제 | 이 계정은 팔로워가 없다. "인스타 팔로워한테 받는 것"으로 읽히면 즉시 자기부정("나는 해당 없음")이 온다. 그래서 관객을 **인스타 밖 지인**으로 명시 |
| "댓글 \"화이팅\" 한 줄 대신" | 적(敵) 인용 | 브랜드 코어 적 = 휘발되는 화이팅. story-canon 규칙대로 **따옴표 인용형으로만** 사용 |
| "누가 얼마를 뒀는지는 아무에게도 보이지 않고" | 의심 선제 해소(돌다리) | "돈 걷는 거 아니냐"의 90%는 **노출 공포**다. 묻기 전에 닫는다 |
| "만들 건 다 만들었는데 아직 아무도 선언을 안 했어요" | 선점 + 역희소성 | §0 축. 자백이 곧 초대장 |
| "보내드려도 될까요? / 그냥 지나치셔도 돼요" | 허락형 CTA + 탈출구 | 플레이북 §2-0. 거절 비용을 0으로 만들어야 답장 비용도 0이 된다 |

| 항목 | 결과 |
|---|---|
| 돈 단어(후원·도네·현금·수익·결제) | **0** ("마음을 두고 가다"·"해내면 네 것" = 어휘표 허용 표현) |
| 링크 | **0** (허락 후 2번째 메시지) |
| 요청형 구걸("~해주세요") | **0** (전부 허락형) |

## 2. 범용 템플릿 2안

### A안 — 관찰·질문형 (부담 0)

**쓸 대상**: 목표는 뚜렷한데 **기록이 오래됐거나 뜸한** 계정, 판매·홍보 DM에 예민해 보이는 계정, 팔로워가 많아 DM을 많이 받는 계정. 아무것도 요청하지 않는 것이 유일한 진입로일 때.

```
{개인화: 구체물 2개 + 시점}, 보고 왔어요.

{관찰 한 줄: 그 기록이 어떤 사람의 것인지, 평가 말고 사실로}

저희는 '해낼게'라는 곳을 만들었어요. 목표를 한 줄로 선언하면 페이지가 생기고, 아는 사람들이 댓글 "화이팅" 한 줄 대신 조용히 마음을 두고 갈 수 있는 곳이에요. 만들어는 놨는데 아직 아무도 선언을 안 해서, 지금은 이게 필요할 분들 얘기를 먼저 듣고 있어요.

하나만 여쭤봐도 될까요. {목표}를 준비하면서 받아본 응원 중에, 아직 남아 있는 게 있나요?
```

- 질문이 의견("어떻게 생각하세요")이 아니라 **과거 경험**인 이유: 의견 질문은 예의상 긍정만 걷힌다(Mom Test). 남는 데이터가 없다.
- 약점: 행동 신호가 안 나온다. 회신은 와도 그게 전환으로 이어지는지는 이 문안으로 알 수 없다.

### B안 — 초대형 ⭐주력

**쓸 대상**: 최근 7일 내 기록 활발 + 목표 D-day/시험명이 문자로 박혀 있는 계정(즉 §1 조건 전부 통과). 기본값은 B다.

```
{개인화: 구체물 2개 + 시점}, 보고 왔어요.

{인정 한 줄: 그 기록의 조건(시간대·기간·병행)을 사실로}

저희는 '해낼게'라는 곳을 만들었어요. "나 {목표} 해낼게"처럼 한 줄로 선언하면 페이지가 하나 생기고, 그 링크를 아는 사람들이 볼 수 있게 두면 댓글 "화이팅" 한 줄 대신 조용히 마음을 두고 갈 수 있는 곳이에요. 누가 얼마를 뒀는지는 아무에게도 보이지 않고, 해내는 날 그건 전부 선언한 사람 것이 돼요.

정직하게 말씀드리면, 만들 건 다 만들었는데 아직 아무도 선언을 안 했어요. 그래서 지금 오시면 말 그대로 첫 번째예요.

어떤 곳인지 먼저 보실 수 있게 페이지 하나만 보내드려도 될까요? 보고 아니다 싶으면 그냥 지나치셔도 돼요.
```

- `{개인화}` 슬롯 채우기 규칙: **고유명사·숫자 2개 이상**(과목명·회로명·D-day·주차·시각) + **시점 1개**(며칠자/몇 주차). 형용사 칭찬("대단하세요")은 슬롯에 넣지 않는다. 채울 게 없으면 발송 자격 없음.
- 자가 점검: 돈 0 / 링크 0 / 구걸 0 / 금지어 0(적-인용 1) / 줄표 0 / 대화 층 ✓ (A안 동일).

## 3. 답장이 왔을 때 — 2턴 응대

### 3-1. 긍정 ("보내주세요" / "오 뭐예요?")

**T1** (1시간 내)
```
반가워요. 여기예요. {링크}

선언 한 줄만 쓰시면 페이지가 만들어져요. 그 링크를 프로필이나 단톡에 두시면 되고, 응원은 이름도 금액도 보이지 않게 들어와요. 해내는 날 그건 전부 님 것이 되고요.
```
**T2** (선언 확인 후 1회)
```
선언 올라온 거 봤어요. 진짜 첫 번째 선언이에요. 쓰시다가 이상하거나 아쉬운 부분 있으면 이 창에 그냥 던져주세요. 지금은 만든 사람이 직접 읽고 고치는 시기라서요.
```
- 장치: 공동 제작자 전환(프로세스 이코노미). "첫 번째"는 이 시점에 **사실**일 때만 쓴다. 두 번째 선언자부터는 이 문장을 지운다.

### 3-2. 미지근 ("아 네…" / "좋네요" / 이모지 하나)

**T1** (같은 날 안에, 딱 한 통)
```
답 주셔서 고마워요. 지금 바로 뭘 하실 필요는 전혀 없어요.

혹시 나중에라도 "이거 진짜 해내야겠다" 싶은 순간이 오면, 그때 한 줄만 남기시면 돼요. 필요하시면 그때 링크 다시 드릴게요.
```
**T2: 없음.** 미지근에 두 번 밀면 그때부터 영업이 된다.
- 장치: 철회(밀어내기). 압박을 거두면 상대의 판단이 자기 것이 되고, 브랜드는 "안 조르는 곳"으로 기억에 남는다.

### 3-3. 거절·의심 ("됐어요" / "이거 돈 뜯는 거예요?")

**거절 T1** (즉시, 이걸로 끝)
```
알려주셔서 감사해요. 더 연락드리지 않을게요. 준비하시는 시험, 잘 되시길 바랄게요.
```
→ 시트 `do_not_contact=Y`, 영구. **T2 없음.**

**의심 T1** (방어하지 말고 전부 공개)
```
그렇게 물으시는 게 맞아요. 모르는 계정이 갑자기 DM을 보냈으니까요. 숨길 게 없어서 그대로 말씀드릴게요.

선언하는 것도, 응원을 받는 것도 전부 무료예요. 님이 저희한테 내실 돈은 0원이고 카드번호를 요구하는 일도 없어요. 저희가 돈을 받는 지점은 딱 하나, 나중에 모인 응원을 현금으로 바꾸실 때 수수료뿐이고 그건 소개 페이지에 그대로 적어둘 거예요.
```
**의심 T2** (그래도 의심 지속)
```
확인해 보시고 판단하셔도 늦지 않아요. 불편하셨다면 여기서 그만 연락드릴게요. 준비하시는 거 잘 되길 바라요.
```
- 원칙: 의심 응답은 실패가 아니라 **에토스 증명 기회**. 이 답장이 캡처되면 그 자체가 신뢰 콘텐츠다("수수료를 먼저 말하는 곳").
- ⛔ 수수료율 **숫자는 확정 전까지 넣지 않는다**(플레이북 회수 3 미해결 승계).
- 자가 점검: 3-1·3-2는 돈 0 / 3-3 의심 T1만 돈 언급 — 이는 상대가 먼저 물었을 때의 허용 예외(플레이북 §2-0). 전 문안 구걸 0 · 금지어 0 · 줄표 0 · 대화 층 ✓.

## 4. 셀프심문 · 레드팀

**Q1 (지정). "이 문안이 스팸으로 읽힌다면, 왜인가?"**
스팸 판정은 내용이 아니라 **대체 가능성**에서 온다. "이 문장이 나 말고 다른 100명에게도 그대로 갈 수 있는가?" 이걸 기준으로 초안을 스스로 쳤더니 실제로 걸린 게 2개였다.
1. 프리테스트 A/C안 첫 줄 "이 꾸준함은 흔치 않아서요" → 누구에게나 붙는다. **폐기**. 대체 = 회로명·주차·시각이 박힌 슬롯 규칙(§2 "형용사 칭찬 금지").
2. "님의 기록을 보고 어울린다고 생각해서 연락드렸어요"(프리테스트 B) → 근거 없는 선발 주장이라 허세로 읽힐 수 있고, 역시 아무에게나 붙는다. **삭제**. 대체 = "누구 보라고 올리는 기록 같지가 않아서"처럼 **그 계정에서만 참인 관찰**.
남은 스팸 리스크: 문단 4개 길이. 다만 짧게 줄이면 정직 고지("아직 아무도 없다")를 뺄 수밖에 없고, 그건 스팸 리스크보다 큰 신뢰 리스크(링크 열고 나서 텅 빈 걸 발견 = "낚였다")라 **길이를 감수**했다.

**Q2. "'아직 아무도 안 했다'가 오히려 죽은 서비스로 읽힌다면?"**
가능하다. 이게 이 리테이크의 최대 리스크다. 방어는 두 겹으로 넣었다. ①그 문장 **앞**에 "만들 건 다 만들었는데"를 붙여 미완성이 아니라 **비어 있음**임을 명시했다(고장 ≠ 신규). ②바로 뒤에 "말 그대로 첫 번째"로 **비어 있음의 이득**을 즉시 회수했다. 그래도 죽은 서비스로 읽히면 그건 문구가 아니라 계정·피드가 답할 문제다(§5 회수 1).

**Q3 (레드팀 — 회의적 수신자 ss7coco 본인). "팔로워 2명인 내 계정에 굳이 DM? 아무한테나 뿌리는 거 아니고?"**
가장 아픈 공격이고, 정확히 이 계정 때문에 문안 구조를 바꿨다. 방어: ①회로명 2개 + 특정 주차 타임스탬프는 실제로 게시물을 열어보지 않으면 못 쓴다 ②"누구 보라고 올리는 기록 같지가 않아서"는 팔로워 수를 아는 사람만 쓸 수 있는 문장이면서 동시에 그걸 지적하지 않는다 ③"영향력/인플루언서" 어휘를 한 글자도 쓰지 않았다. 잔존 리스크: 그래도 뿌리는 거라고 느끼면 무응답으로 끝난다. 그건 감수한다. **거짓 아부로 응답률을 사는 것보다 무응답이 낫다.**

**Q4. "0번 게이트 — 스킬·근거·품질헌법?"** hook-angle-lab 실호출(첫 줄 패밀리 = 리버설·컨페션·구체증거 비교 후 선별), WebSearch 실조사 1건, writing.md·marketing.md·플레이북·프리테스트·브랜드 정본·post-copy 실 Read. 금지어·줄표 자가 grep 완료(§1-2).

## 5. ⛔ 회수 필요 (회장 판단)

1. **발송 전 계정 상태 확인 1건**: 이 DM은 "만들 건 다 만들었다"고 말한다. 받은 사람은 십중팔구 프로필을 먼저 눌러본다. ①인스타 프로필 링크가 실제로 선언 페이지로 연결돼 있는지 ②피드 예시 선언 카드에 "예시" 표기를 넣을지(프리테스트 회수 2 미결) 이 둘이 정리되지 않은 상태로 보내면 문안의 정직함이 프로필에서 깨집니다. **추천 = 링크 연결 확인 + "예시" 한 줄 표기 후 발송.** 미표기로 보내면 "다 만들었다더니 선언 카드는 가짜네" 한 방에 신뢰가 무너집니다.
2. **첫 통을 ss7coco 1명으로 끝낼지, 같은 문안으로 5~10명까지 갈지**: 추천 = **ss7coco 포함 3명에게 먼저 보내고 48시간 대기.** 반응 0이면 첫 줄 슬롯 규칙부터 고쳐서 다음 배치. 한 통만 보내면 무응답이 문안 탓인지 우연인지 판별이 안 되고, 15명을 한 번에 태우면 첫 실측 전에 표본을 잃습니다.
