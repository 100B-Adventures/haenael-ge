## 어떻게 했나

1. 접속. 원본은 키체인 `supabase-db-password / haenael-ge`, 대상은 회장이 준 값을
   `supabase-db-password / haenael-ge-new` 로 저장. **풀러 접두가 다르다.**
   원본 `aws-1-ap-northeast-2`, 대상 `aws-0-ap-southeast-1`. 직접 호스트는 IPv6 라 안 붙는다.
2. `auth.users` / `auth.identities` 먼저. `member.id` 가 `auth.users(id)` 를 참조한다.
   생성 컬럼(`confirmed_at`, `email`)은 COPY 에 못 쓰므로 제외한다.
   CI 용 QA 계정은 대상에 이미 있어 제외한다.
3. public 스키마를 `pg_dump --data-only | psql` 로 넘긴다.
4. **트리거를 반드시 끈다.** 켜 두면 적재 중 웰컴 클로버 트리거가 돌아
   원본에 없는 `cheer`·`clover_ledger` 행을 만들고 기본키가 충돌한다.
   `set session_replication_role = replica` 가 대상에서 설정 가능하다.
5. 시퀀스 보정. `setval` 14개를 돌려 다음 insert 가 충돌하지 않게 한다.
