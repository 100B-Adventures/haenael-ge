- Supabase anon/publishable (공개, 프론트 사용): `sb_publishable_*` 및 legacy anon JWT

- Supabase 액세스 토큰(CLI): 환경변수 `SUPABASE_ACCESS_TOKEN` (회장 개인 PAT, 로컬 관리)
- 엣지함수 시크릿(배포 시 설정 필요, 값 미보유): 토스 결제 키, 카카오 OAuth, 알림톡

## 환경변수 이름 (Vercel)

- `NEXT_PUBLIC_SUPABASE_URL` — 새 프로젝트 URL로 재배선 필요
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — 새 프로젝트 publishable로 재배선 필요
- `SUPABASE_SERVICE_ROLE_KEY` — 서버 전용, 재배선 필요

## 배포·롤백 절차

1. Supabase: `supabase link --project-ref <ref>` → `supabase db push --linked` → `supabase functions deploy`
2. 함수 시크릿: `supabase secrets set <NAME>=...` (값은 회장 보유분 사용)
3. 웹: PR → main 머지 → Vercel 자동배포. 롤백 = Vercel 이전 배포 promote
4. DB 롤백: 마이그레이션은 전진 전용. 되돌림은 보상 마이그레이션 신규 작성
