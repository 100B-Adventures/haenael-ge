## 가입(Auth) 구성·검증 상태

- 카카오: 커스텀 OAuth(엣지함수 `auth-kakao`). 운영 `/auth/kakao/start?redirect=/me`가 카카오 인증 호스트로 307 리다이렉트하고 state를 발급하는 것까지 관찰. 실제 카카오 동의·콜백·신규 member 행 생성은 이번 컷오버에서 미검증.
- 운영 Auth: 새 프로젝트에 전용 QA auth-only 사용자를 생성하고 비밀번호 로그인, Supabase 세션 쿠키, Vercel `/cashout` 200 렌더, 콘솔 오류 0을 관찰. QA 사용자는 제품 `member` 행을 만들지 않는 안전 계약 유지.
- 구글·애플: `supabase.auth.signInWithOAuth`. Supabase Auth 대시보드에 공급자별 client id/secret + 리다이렉트 URL 등록 필요.
- 공통 서버 시크릿: `NOTIFY_INTERNAL_TOKEN`(웹 env ↔ 함수 시크릿 동일 값), 결제 `TOSS_*`, 알림톡 키.
