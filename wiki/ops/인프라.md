## Storage cleanup 롤백 계약 (2026-10-20)

운영 적용 전용 보상 마이그레이션에서만 실행한다. 마이그레이션 파일 자체를 되감지 않는다.

```sql
SELECT cron.unschedule('purge-abandoned-goal-covers')
WHERE EXISTS (SELECT 1 FROM cron.job WHERE jobname = 'purge-abandoned-goal-covers');
SELECT cron.unschedule('drain-storage-cleanup-queue')
WHERE EXISTS (SELECT 1 FROM cron.job WHERE jobname = 'drain-storage-cleanup-queue');
SELECT cron.unschedule('monitor-storage-cleanup-drain')
WHERE EXISTS (SELECT 1 FROM cron.job WHERE jobname = 'monitor-storage-cleanup-drain');
```

`settle_storage_cleanup`의 `goal_cover_asset` 하드 삭제는 `status='DELETED'`, 격리 버킷 쌍 일치, 활성 커버 미참조가 모두 성립한 tombstone만 대상으로 한다. 이 함수가 한 번 삭제한 행은 DB 롤백만으로 복구하지 못하므로, 롤백 전에는 queue drain을 먼저 중지하고 Storage와 DB 보존 스냅샷을 확보한다.
