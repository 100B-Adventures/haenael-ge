## 0. 사용 규칙 (하위모델·운영자 필독)

1. **3태그 필수**: 모든 카피는 ①층(선언-단호 / 대화-따뜻) ②면(주인공 / 응원자 / 브랜드공개 / 주인공-개인화면) ③심리 트리거를 갖는다. 태그가 안 맞는 자리에 쓰지 마라 — 예: 선언-단호 카피를 CS 답변에 쓰면 차갑고, 대화-따뜻 카피를 스레드 첫 줄에 쓰면 죽는다.
2. **면 정의**:
   - **주인공 면** = 선언 페이지·공유 카드·프로필 임베드 → 돈 언어 0개 절대.
   - **주인공-개인화면** = 본인만 보는 알림·마이페이지·환전창 → 돈 언어 허용(정본 P4 알림 카피 준거).
   - **응원자 면** = 결제 터치포인트·응원자 대상 광고 → 돈 언어 허용, 단 행위 선언형("밀어줄게/두고 갈게")만. 요청형 금지.
   - **브랜드공개 면** = 스레드·랜딩 hero·유튜브 배너 등 브랜드 자기 발화 → 슬로건·돈 담론 허용.
3. **금지어** (발견 즉시 반려): 쏘다·플렉스·기부 / 도와주세요·후원 부탁 / 랭킹·TOP·1등 / 상금·벌금·내기 / 코인·캐시·포인트 / "화이팅!" / '같이 공부'·'스터디 모집'.
   - 예외 ①: "화이팅"을 **적(휘발되는 관습)으로 인용**할 때만 허용.
   - 예외 ②: **타인 발화 인용**("합격하면 쏜다던 사촌형") — 정본 P4 대표 카피 준거. 브랜드 자기 발화로는 절대 금지. [⛔ 회수 필요: 이 인용 예외의 공식 승인 — 하단 참조]
4. **온도** = 미온. 호들갑·신파·이모지 과잉 금지. 🍀 는 브랜드 시그니처로 문장 끝 1개까지만.
5. 🗣 표시 = 페르소나 실입말 기반 카피(persona.md 원문 유지·변형 최소화).

## 6. [실험] 판정 게이트 (기본값)

- 스레드 후킹 카피: 게시 후 48h 조회 대비 댓글률 상위 50% 미달 2회 연속 → 해당 카피 회수, 같은 필러 백업으로 교체.
- 결제창·알림 마이크로카피: 콜드스타트 P2(결제 오픈) 이후 결제 이탈률로 판정 — 기준치는 P2 개시 시 설정. 그 전까지 기본값 = 본 문서 1순위 카피.
- 침식 감시(정본 §2-4 ⓓ): 댓글·공유 캡션에서 금액 언급 발생 시 해당 카피 즉시 검토.

## 7. 셀프심문 (CoVe + 레드팀)

- **"이 카피가 역화한다면 왜?"** — 최대 리스크 = '쟤 돈 걷네' 프레임 재점화. 점검 결과: 돈을 직접 언급하는 카피(P3-05~07, P4-01~03, P4-05~08)는 전부 응원자 면·브랜드공개 면·주인공-개인화면 태그 — 주인공 공개면 태그를 가진 카피 중 돈 단어 포함 0건(육안 + 태그 검증). P2 전체에 돈·후원·환전·현금 토큰 없음.
- **"P2-03(기분이다)이 선언 안 한 다수를 모욕해 브랜드 반감을 사면?"** — 맞는 위험. 그래서 면을 '스레드 첫 줄 전용'으로 못박고 주인공 면 금지 명기. 논쟁 댓글엔 P1-07(대화층 완충)로 대응.
- **"금지어 검증했나?"** — grep 결과: '쏘다' 계열은 P4-01 인용부·금지어 목록 자체에만 존재, '화이팅'은 적 인용(P1·P3-08)에만 존재. 브랜드 자기 발화 위반 0건.
- **"0번 게이트 — 스킬 실제 호출했나?"** — hook-angle-lab·social-post-packager 실호출로 후킹 패밀리 비교·플랫폼 규격을 거쳐 정제함(트랜스크립트 대조 가능).
